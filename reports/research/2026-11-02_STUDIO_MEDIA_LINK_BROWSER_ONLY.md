# 02.11.2026 · Студия M1lash — поле видео по ссылке

Запрос владельца: вставлять ссылку на стороннюю страницу, в частности HDRezka, и получать возможность скачать видео.

## Реальная архитектура
- Сайт: `site/studio/index.html`, существующий раздел `Клипы` рендерится из `site/studio/clips_ui.js`.
- Сайт опубликован на **GitHub Pages**: статический HTML/JS, серверного извлечения потоков нет.
- `AGENTS.md` §3 запрещает использование пиратских сайтов как киноисточников студии.

## Сделано
- В существующем разделе `Клипы` создан блок «Скачать видео по ссылке» без изменений нижней навигации.
- Принимаются прямые HTTPS-файлы `.mp4`, `.m4v`, `.webm` без встроенных логинов и нестандартных портов.
- В результате появляется ссылка открытия/сохранения, без отсылки введённого URL в GitHub.
- HDRezka/Rezka как страницы, HTML player pages, `.m3u8`, DRM и недопустимые схемы получают **честное объяснение**, а не ложную «Скачать 1080p».
- Прямой MP4 может открыться вместо скачивания из-за браузера и чужих заголовков HTTP; `download` cross-origin не гарантируется. Разрешение 1080p **не проверено**: качество определяется файлом.

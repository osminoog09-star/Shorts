## Формат
- **POV от второго лица**: «Ты пасёшь табун… Ты понимаешь…» — зритель и есть герой. Один рассказчик, без диалогов вслух (реплики пересказаны).
- **8 уровней ≈ по 3 мин** (00:04, 03:04, 05:11, 07:54, 11:34, 14:23, 18:32, 22:05) — карьерная лестница одного героя от мальчишки до вождя.
- **Рефрен-якорь каждого уровня**: «Шрам уровня: <метка>» — физическая или душевная (обмороженная щека → строчка на груди → новое имя → «имя, которое мать произносит как чужое» → порез от брата → «ты жив» → «победа, которую одержал не ты» → «дом, из которого ты больше не уедешь»). Метки идут от тела к душе — нарастание.
- **Связка между уровнями**: «Уровень N. <Роль>. Прошлый отвечал за X, этот отвечает за Y» — понятная ступень ответственности.
- **Хук 0–10 с**: без вступления сразу «Уровень первый. Табунщик» + сильный образ места (степь, небо больше земли). В описании — эмоциональный крючок (хвост коня → знамя через полтора века) и **кольцевая композиция**: предмет из 1-го уровня возвращается в финале.
- **Финал**: герой-вождь передаёт тот же предмет новому мальчишке, не договаривает девиз — «Шрам уровня: дом, из которого ты больше никуда не уедешь». Тихий, горький, без экшена.
- Честность канона: «Стоп, тут честно. По канону…» — рассказчик признаёт, где додумывает.

**Графика поверх кадра:**
1. **Карточки-термины** по центру тёмной плашкой: «КРОВНАЯ ВРАЖДА / Кто начал, уже никто не помнит», «ХАН ВСЕГДА ПОБЕЖДАЕТ» — вводят понятие мира одной строкой.
2. **Карточки-«полароиды» с подписью** в углу: «МОХНАТЫЙ, ЗЛОЙ», «БОЕВОЙ МОТОЦИКЛ, СВОЙ», «ОРКИ С РАКЕТНЫМИ РАНЦАМИ», «ТЭМУР · кровный враг» — глоссарий существ/машин/людей без остановки рассказа; иногда веер карточек.
3. **Цитаты-субтитры** слева внизу на тёмной плашке на ключевой фразе («Вражда закончилась не на поединке», «Новый шрам ложится на другую»).
4. Подписи мест («У СТЕН ЦЮАНЬ ЧЖОУ»).
**Мотивы, проходящие через весь ролик:** бунчук/хвост коня (ур. 1 → финал), обмороженная щека, мать в юрте (ур. 1 → ур. 4), кровник-ровесник (ур. 3 → ур. 7). Герой взрослеет и стареет в кадре (мальчик → юноша → седой).
**Чёрный кадр-пауза** перед кульминацией одного уровня.

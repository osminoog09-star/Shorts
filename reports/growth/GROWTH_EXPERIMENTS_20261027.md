# M1lash — план тестов роста без изменения публикаций
**Дата:** 27.10.2026 · **Исполнитель:** ChatGPT/Codex · **Статус:** проект; не создаёт постов и не переписывает AGENTS.md.
**Вход:** RESEARCH_20261027.md, PEER_REVIEW_PROMPTS_20261027.md, reports/videos.csv, reports/style_experiment.md и weekly reports.

## Зачем: на что влияет каждая правка

| Проблема | Нужный сигнал | Что реально менять |
|---|---|---|
| Зритель свайпает | shown in feed, chose to view («остались смотреть») | первый кадр, понятность темы, первые 2 сек |
| Смотрит и уходит рано | AVD, avg. percentage viewed, retention curve, engaged views | длительность, визуальные действия, сцены без пользы |
| Досматривает, но не подписывается | подписки на 1000 engaged views, returning viewers | единое обещание канала, содержание серий, естественный CTA |
| Shorts получает охват, а long нет | related video clicks, VOD traffic, VOD retention | самостоятельная нарезка с честным обещанием длинного, related-video линк |
| Время/стиль «не зашёл» | разбивка по форматам и темам, одинаковый возраст 48ч/7д | менять только один фактор в каждой серии тестов |
| Обложки не кликаются / разочаровывают | long-form CTR, watch time share A/B, первая минута | визуальный объект + ясный заголовок, соответствие обещанию |

**Критично:** YouTube не предоставляет в любом внешнем коннекторе все метрики. Если нет показов Shorts, chose-to-view или retention, ставить N/A и не придумывать причины.

## Базовые вычисления

- Engaged view rate = engaged views / shown in feed (если оба значения доступны и совместимы по определению/окну; иначе N/A).
- Chose-to-view = нативный показатель YouTube Studio; НЕ считать его суррогатом из public views.
- Avg percentage viewed = YouTube Studio metric (или AVD / duration для сопоставимых определений); ролики-петли могут давать >100%.
- Subs / 1000 engaged views = subscribers gained / engaged views × 1000, если по конкретному ролику доступны.
- Сравнение 48ч: от фактического published_at, не календарная дата на сайте. Коннекторные daily-значения допустимы как суточный срез, **не замена 48ч**.
- Long отдельно: impressions, impressions CTR, average view duration, first 30s retention, watch time share of thumbnail/title variants.
- Выбор победителя: минимум n=3 похожих выпуска для каждого условия, ориентир из skills/channel-analytics/SKILL.md — улучшение индекса/досмотра ≥20%; при малых выборках — предварительная гипотеза, НЕ статистически доказанная победа.
- Время реакции: первые 48ч диагностические, через 7 дней отчёт, через 28 дней — проверка устойчивости; публичные просмотры могут позднее расти.

## Приоритетные 3 теста (снять шум, не мешать друг другу)

### Тест A — тип первого кадра
- **H-A:** понятный, уже ДЕЙСТВУЮЩИЙ объект и последствие за 0–2 сек приводят к большему chose-to-view, чем обычная вводная карточка.
- Условия: одинаковые формат и близкая тема/длина/голос/стиль, в каждой серии по ≥3 Shorts; A = действие/авария; B = вопрос/надпись. Без дублирования одного ролика и без обхода расписания.
- Приоритет: высокий. Промпт-версия: HOOK.v2 после реальных данных, не менять исходную библиотеку.

### Тест B — «смотри как работает», а не AI-слайд
- **H-B:** визуально объяснённый процесс с предметом даст выше avg % viewed, чем абстрактные текстовые карточки.
- Сначала собрать подборку уже опубликованного материала, пометить наличие механического действия. Новые шоты в рамках тех же утверждённых S1–S9 / D2-D25-D3; не путать эффект визуального стиля с эффектом темы.
- Приоритет: высокий; проверить по 3+ роликам, если нет достаточных данных — оставлять гипотезой.

### Тест C — причина подписаться после просмотра
- **H-C:** тематический CTA «в следующем видео проверим...» или честная связка с длинным даст больше subscribers/1000 engaged views, чем общее «подпишись».
- **Ограничение владельца:** утверждённая говорящая концовка «Подпишись! И спасибо...» остаётся без изменения. Проверяем тематическую формулировку ДО аутро и метаданные/related-video без подмены финала.
- Измеряем подписки и переходы по Shorts на long (если возможно), не «лайки = подписки».
- Приоритет: средний.

Параллельный эксперимент стилей S1–S9 уже ведётся в reports/style_experiment.md. **Не создавать ещё 9 независимых тестов за один месяц**; при интерпретации учитываем стиль как конфаундер. Если гипотеза C повлияет на длительность — выровнять общую продолжительность.

## Рубрика выбора темы для продюсера (перед сценарием)

Оценить по 0–5 каждый пункт и суммировать:
1. Широкая понятная проблема/загадка в двух секундах.
2. Реальное движущееся визуальное доказательство, не просто интерфейс/текст.
3. Факты с двумя независимыми проверяемыми ссылками.
4. Неожиданный поворот/ясный конец.
5. Причина посмотреть другой выпуск именно M1lash.
6. Достижимая стоимость/время/лицензия.
**Максимум 30:** ≥24 — делать первый концепт; 19–23 — усилить хук/визуал; <19 — в backlog. Эти пороги — редакционное внутреннее правило, не модель рекомендации YouTube.

**Hard reject** вне баллов: сенсация без источников, заимствованное чужое видео/музыка без прав, актуальная трагедия ради шутки, без проверки лицензии, занятый чужой слот/тема.

## QC ворота до слова «готово»

1. Сценарий: 2 независимых источника на каждый новый проверяемый факт. Данные и даты свежие, если news.
2. Голос: утверждённый голос, читаемо/понятно, совпадает с липсинком; музыка тише речи; лицензия и credit подтверждены.
3. Изображение: первый кадр интригует, движения настоящие, визуал объясняет сказанное, на мобильном читаемо, части тела/механизма не меняются между шотами, нет «коллажа кадров».
4. Разрешение/звук: ffprobe и полный decode — необходимы, но НЕДОСТАТОЧНЫ. Финальный файл просмотреть и прослушать на нормальной скорости целиком. Записать таймкоды обнаруженных дефектов и правки.
5. Юридическое: исходники картинки/видео/музыки и лицензии отмечены, реалистичный AI content помечен согласно YouTube.
6. Сетка: только согласованный слот, автор, предельное количество Shorts; **проверить** занятость и статусы, не объявлять «вышло» без YouTube ID.
7. Упаковка: название без ложного обещания; короткое описание, источники, 2–3 обложки на длинные; связанный ролик, если доступен.

## Чего не делать

- «Публикуй 5 в день и алгоритм заметит» — официальная справка этого не подтверждает.
- «Хештеги/время слота гарантируют миллионы» — проверка эффективности не доказывает такой зависимости.
- «YouTube забанил на 1500» — без Studio-метрик такой вывод недоказуем.
- «Модель Claude/Gemini сказала» — без реального ответа и даты это выдумка.
- «24 секунды лучше 45» — это зависит от плотности, темы и зрителей; сперва измеряем.
- «Каждые 2 секунды любой переход» — динамика должна объяснять историю, а не слепить.

# M1lash — ролики и публикации

Готовые видео, рендеры, эксперименты и история публикаций. Существующие запланированные публикации в Metricool сохраняются.

**Прямая публикация на YouTube (RU/EN)**: см. [publishing/README.md](publishing/README.md), workflow **YouTube direct · review then schedule**. По умолчанию dry-run; новая публикация возможна только после настройки OAuth и явного `execute=true`.

Metricool пока остаётся для старой очереди и аналитики. Скрипт не требует платного тарифа Metricool и не используется для публикаций в Instagram.

3. 5. Граница автономии: до приватной заливки без даты (§6). Дату/публикацию ставит только Денис кнопкой «Заливаем». Траты, новые форматы, стиль нового формата, удаление роликов — только решение Дениса (grill-me вопросом в чат, не останавливая остальную работу).

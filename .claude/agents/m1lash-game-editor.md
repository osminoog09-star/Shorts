Ты монтируешь игровые серии. Сначала AGENTS.md §3, §4, §12, skills/ext/ffmpeg-skill, skills/awa-video-reel (приёмы подачи), skills/m1lash-studio «Уроки».
Вход: запись + transcript.json/silences.json/highlights.json от game_watch.py. Делай на ПК, не в LLM: решения по таймкодам принимай по транскрипту и данным, резку — ffmpeg (точные cut без перекодирования где можно, финал NVENC h264 1920×1080 60/30 fps).
Серия: первые 15 с — самый сильный момент серии (хук), затем по порядку; вырезать паузы >2 с, загрузки, меню, повторы смертей (оставить смешные); цель 20–40 мин без растягивания; главы каждые 3–6 мин → в описание; громкость голоса и игры выровнена (голос −16 LUFS дорожка, игра ниже на 6–10 дБ); вставки-синтез Дениса только по манифесту m1lash-voice; концовка v7 horizontal через tools/assemble_with_outro.py.
Гайд: 3–8 мин «как пройти X» — только нужный отрезок, текстовые плашки шагов кодом.
Выход: MP4 + chapters.txt + edit_manifest.json (какие отрезки исходника взяты) → m1lash-qa.

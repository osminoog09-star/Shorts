Ты делаешь игровые Shorts. Сначала AGENTS.md §7 (хук 2 с, ≤59 с с концовкой), §4, skills/awa-video-reel, skills/ext/ffmpeg-skill.
Кандидаты — highlights.json (всплески громкости, смех/крики в транскрипте, резкие события); выбери 2–4 лучших, 20–45 с каждый, начинай за 1–2 с до события. Вертикаль 1080×1920: геймплей по центру с умным кропом (действие не обрезать), при необходимости размытый фон; крупные кинетические субтитры по словам; живой голос Дениса чистый. Название игры можно писать (это не кино-Shorts §8). Концовка v7 vertical целиком. Музыку игры, если ловит Content ID, приглушить. Выход → m1lash-qa → m1lash-packaging.

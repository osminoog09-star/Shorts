# M1lash Director · режиссёр

Читать `AGENTS.md`, `STRATEGY.md`, `CODEX_NOTICE.md`, `reports/learnings.md`, `skills/vizavi-motion/SKILL.md` и `references/quality-upgrades.md` перед каждым проектом. Пользовательский бриф важнее дефолтов. Не публиковать без поручения.

## Вход
Сценарий, голос, длительность, формат, референсы, ограничения бюджета, библиотека героев и предыдущий аудит.

## Обязательные выходы
1. `director_brief.md`: тезис, эмоциональная дуга, хук 0–5 с, эскалация, 2–3 поворота, развязка, финал.
2. `shotlist.csv`: `shot_id,scene_id,start_s,end_s,spoken_words,location,shot_size,action,emotion,camera,foreground,middle,background,lighting,props,sfx,transition,asset_refs,status`.
3. `animatic.mp4`: набросок всего сюжета с **настоящими таймингами** озвучки, прежде полного рендера.
4. `director_review.md`: дефекты, исправления, заново просмотренные сцены.

## Режиссёрские правила
- Каждая реплика вызывает видимое изменение событий: действие, реакция, переход, взаимодействие с предметом; «герой стоит и говорит» допустим только мотивированной паузой.
- На каждый сюжетный блок минимум 3 класса кадров: общий → средний → крупный/предметный; **не подменять** их цифровым zoom одного рисунка.
- Обосновывать монтаж причиной: что зритель узнал/почувствовал; крючок каждые 1,5–2 минуты; не менять кадры ради счётчика.
- В shotlist каждые ~3–8 секунд новое осмысленное изображение, более длинные кадры лишь по драматургии.
- Новое окружение рисовать / моделировать как устойчивую локацию, согласованную по перспективе, источникам света и реквизиту.
- Персонажу: единый model sheet (анфас, профиль, 3/4, 6+ эмоций, жесты, рот, руки), чтобы он узнавался между кадрами.
- События и диалоги: планировать паузы, взгляд, ответную реакцию, второстепенное действие, предмет в руке.
- Субтитры не заслоняют главную игру; PiP ведущего — утверждённый `HostCorner` / `Narrator2`, не выдумывать нового.
- Для длинного фильма финал — реальная последняя реплика → реакция → благодарность/CTA → фирменное окончание; не допускать пустой аудиохвост.
- Заимствовать из референсов **принципы**, не чужих персонажей, озвучку и сцены.
- Режиссёр даёт обязательное решение `GO/NO-GO`: если аниматик/персонажи плохие — не тратить ресурсы на 14-минутный рендер.

## Оценивание
Оценка 0–5 по: драматургия, соответствие действию, разнообразие постановок, актёрская игра, свет/материалы, темп, звук, финал. Любая категория <3 означает `NO-GO`. Указывать конкретные кадры и таймкоды, не субъективный «лучше».

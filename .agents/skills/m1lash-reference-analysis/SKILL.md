# M1lash Reference Analysis · исследователь видео

Получить исходный MP4 либо легальный доступ к образцу, цель проекта и права на использование. Нельзя выдавать догадки из коллажа за покадровый просмотр.

## Сбор фактов
- `ffprobe`: длительность, FPS, размер, кодеки; `ffmpeg` кадры в репрезентативных таймкодах (вступление, середина, развязка) и кадры на склейках.
- Построить `reference_audit.md` с датой, источником, разрешением использовать, жанром, ограничениями выборки.
- Сценический журнал: `time_in,time_out,location,characters,shot_size,camera_motion,action,expression,background_depth,text,sfx,music,function`.
- Разметить хуки первых 5 сек, точки разворота, смешные паузы, plot beats, продолжительность отдельных сцен.
- Классифицировать «настоящая новая постановка / та же поза с панорамированием / полустатичная иллюстрация».
- Анализ звука раздельно: диктор, акценты, ambience, музыка, тишина, стыки; без заявлений об идеальности, если слуховой просмотр неполный.
- Сравнить с нашим проектом matched timecodes: одинаковая функция сцены, разнообразие окружения, число действительно уникальных кадров, соответствие речи, мимика, действия.
- Выписать **переносимые техники**: шот-лист, силуэт, темп, масштаб, свет, сценический реквизит, реакция персонажей.
- Не использовать чужие кадры, диалоги, персонажей, музыку и оригинальный монтаж без разрешений. Исследование != лицензия.
- Сформировать `reference_lessons.json` с полями `technique,observed_at,expected_benefit,application_scene,verification_method,confidence`.
- Рекомендация учитывает бюджет и возможности инструментов: не обещать «достичь того же уровня» из простых графических примитивов.

# Mercury Motion Studio

Личная видеостудия M1lash. Браузерная оболочка размещается на GitHub Pages; фоновые задачи — в GitHub Actions. Новый самостоятельный инструмент; материалы курса Vizavi не скопированы.

## Что работает без ключей

- Редактор сцен и аудио, 16:9 и 9:16, 720p/1080p/4K в браузере.
- Canvas-анимация: карта Natural Earth, титры/факты, схемы, сравнения, таймлайны, оригинальные рисованные роботы.
- Предпросмотр, PNG, SRT, JSON с медиа, нарезка отдельного Shorts-проекта.
- Локальное сохранение в IndexedDB. Черновики и аудио не отправляются на GitHub, пока пользователь явно не отправит задание.
- Экспорт браузером в WebM или MP4 (если браузер поддерживает кодек), в реальном времени, с загруженным/Google-голосом и своей музыкой.

Это набор шаблонов анимации, не универсальная генерация любых сцен или полноценный 3D-редактор. Сложные 3D/сгенерированные видеосцены требуют отдельного движка/провайдера. Кинематографическое качество не гарантировано автоматической сборкой шаблонов.

## Google

В настройках можно добавить Gemini API key **в память вкладки**. Он передаётся только Google, не сохраняется в браузере, исходниках или проекте. После перезагрузки нужен повторный ввод.

- Сценарий: generateContent + Google Search grounding, модель настраивается.
- Голос: Gemini TTS, аудио декодируется и сцены синхронизируются с фактической длительностью реплик.
- Разбор референса: Interactions video understanding, публичная YouTube-ссылка. Разбирается подача, не копируется контент.
- API имеет отдельные лимиты/тарифы. Возможны ограничения региона, модели, проекта. Подписка ChatGPT не является API-доступом.

Живые Google-запросы пока не подтверждены: тест из среды разработки вернул HTTP 400 `User location is not supported for the API use`. Это не доказывает неверный ключ. Никакой пользовательский ключ в репозитории не хранится.

## GitHub Actions

- `motion-pages.yml` — размещение только браузерных файлов.
- `motion-trends.yml` — ежедневные измерения YouTube, сохранение `data/trends.json` и обновление Pages. Требуется `YOUTUBE_API_KEY`. Первый отчёт получен через vidIQ. Основной ежедневный радар дополнительно настроен задачей ChatGPT через подключённые vidIQ/GitHub, без пользовательского YouTube API key. Прямой Actions scanner — дополнительный путь; без ключа он сохраняет старые измерения с честной пометкой настройки.
- `motion-render.yml` — JSON в `jobs/motion/*.json` запускает озвучку по сценам и MP4. Максимум 2 задания в одном push. Результаты — приватные артефакты Actions на 14 дней, скачиваются владельцем с GitHub.
- `motion-autopilot.yml` — подготовленный конвейер двух языков; **производство отключено до настройки**. Выбор оригинальной темы, разбор первого фрагмента референса, сценарии, проверка минимум двух доменов источников для центральных фактов, отдельная проверка моделью по текстам, синхронизация с голосом, MP4 и загрузка в строго проверенный канал.

Проверка моделью — фильтр ошибок, не гарантия истины. Неудачный фактчек останавливает автоматический выпуск. Тренды — выборка по поисковым запросам, не весь YouTube; средний VPH отличается от текущего. `recent_views_per_hour` рассчитывается только после повторного замера.

### Однократная настройка для фоновой работы

1. Включить Pages → Source: **GitHub Actions**.
2. В Settings → Secrets and variables → Actions добавить:
   - `GEMINI_API_KEY`
   - `YOUTUBE_API_KEY` (YouTube Data API v3 включён в Google Cloud)
   - `YOUTUBE_OAUTH_CLIENT_ID`, `YOUTUBE_OAUTH_CLIENT_SECRET`
   - `YOUTUBE_REFRESH_TOKEN_RU`, `YOUTUBE_REFRESH_TOKEN_EN`
3. OAuth должен включать `youtube.upload` и `youtube.readonly`. На своём ПК выполнить `pip install google-auth-oauthlib requests`, затем `python motion-studio/automation/oauth_setup.py --client /путь/к/локальному/client.json --lang ru` и повторить `--lang en`, выбрав другой канал. Приватный client JSON и refresh tokens не загружать в репозиторий и чат. OAuth-приложение Google и его consent screen настраиваются владельцем; ограничения Google проверяются реальной загрузкой.
4. В `automation/config.json` указать **разные реальные** channel ID, разрешённые даты выпуска, видимость, бюджет запросов и включить `enabled`. Можно сохранить конфигурацию из интерфейса с временным GitHub fine-grained token (только Shorts: Contents write, Actions read). Секреты в конфигурации запрещены.
5. Для входа кнопками в браузере нужен отдельный OAuth **Web** client ID и origin GitHub Pages в Google Cloud. Это временная сессия для проверки канала, она не заменяет фоновые refresh tokens.

Для публичной загрузки используются только заданные будущие даты в 19:00 Europe/Tallinn; по умолчанию загрузка private. Календарь M1lash из `AGENTS.md` остаётся обязательным: не занимать чужие даты. Две языковые версии публикуются на разных каналах. Существующие чужие видеопроекты и очереди не меняются.

Автопилот сохраняет журнал в `data/production.json`; неопределённый результат загрузки не повторяется автоматически. При смене видимости/канала проверяйте первую загрузку вручную. Фоновое создание Shorts с публикацией пока не реализовано; в редакторе доступна ручная нарезка в отдельный проект. Профессиональный монтаж произвольных исходников/3D-сцен и генерация авторских thumbnails — следующий этап, не выдаются за готовую функцию.

## Проверки и ограничения

JavaScript проходит `node --check`, Python — `py_compile`. Браузерная проверка интерфейса через реальный Chrome. Отдельный smoke workflow проверяет рендер короткого ролика без внешних AI-вызовов. Голос Google, OAuth, работа с платными API и автопубликация требуют реальных секретов и не считаются проверенными сборкой сайта.

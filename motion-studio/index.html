Фоновое производство

ТРЕБУЕТ НАСТРОЙКИ

Ежедневный поиск → оригинальная тема → версии RU/EN → проверка источников → голос → рендер → загрузка в правильный канал. Ошибка фактов, OAuth или лимита останавливает выпуск и попадает в журнал.

Без GEMINI_API_KEY, YOUTUBE_API_KEY и отдельных OAuth refresh tokens фоновый конвейер не активирован. Вход кнопками выше даёт временную сессию, не постоянный фоновый доступ.

Защищённые секреты GitHub ↗

Нужны GEMINI_API_KEY, YOUTUBE_API_KEY, YOUTUBE_OAUTH_CLIENT_ID, YOUTUBE_OAUTH_CLIENT_SECRET, YOUTUBE_REFRESH_TOKEN_RU, YOUTUBE_REFRESH_TOKEN_EN. Ключи и refresh tokens не вставляются в JSON. Для Google TTS лимит запросов нужно поднять с учётом числа сцен.

ПРОЦЕСС БЕЗ МАГИИ

Как устроена студия

Адаптация форматов: свой сценарий и визуалы на основе разбора удачной подачи.

1. Идея и сценарий

Вставь свой текст: пустая строка начинает новую сцену. Или подключи Gemini и нажми «Написать сценарий»: модель исследует тему через Google Search и вернёт редактируемые сцены с источниками. API может тарифицироваться Google.

Без ключа: скопируй задание для ChatGPT, получи JSON и импортируй его. Перенос вручную — генерация и рендер не требуют платного видеогенератора.

2. Анимация

Контуры Natural Earth, подсветка стран, маршрут, плавный зум и титры рисуются на Canvas. Кроме карт есть сравнения, таймлайны, схемы, персонажи и кинетическая типографика. Это набор рисованных кодом шаблонов, а не универсальная генерация любых 3D-сцен. Карта современная и обзорная, не историческая и не юридический источник границ. Для древней истории границы нужно готовить отдельно.

3. Голос

Загрузи готовый голос или отправь сцены на GitHub: workflow озвучит каждую сцену через edge-tts и соберёт MP4. Прослушивание в браузере — только проверка текста, этот голос не входит в запись.

4. Готовое видео

Браузер записывает анимацию и загруженные аудиофайлы в WebM, а при поддержке — MP4. Держи вкладку открытой: запись занимает столько же времени, сколько ролик. 4K требует мощного устройства. Звук браузерного диктора не записывается.

Рендер на GitHub создаёт MP4 720p/1080p с голосом Дмитрия по сценам. Результат — артефакт запуска Actions. Он не публикуется на YouTube. Нужен временный токен только на этот репозиторий с Contents: write и Actions: read.

5. Проверка и Shorts

Проверь факты и ссылки, отметь проверенные сцены, прослушай голос. Кнопка Shorts создаст отдельный вертикальный проект до 59 секунд из текущей сцены и следующих. При загруженной общей дорожке звук вырезается по таймлайну.

Что показано у Vizavi

В уроке описаны 7 этапов: выбор темы, факты, голос, HTML-анимация, сборка регионов, монтаж, упаковка. На vizavi.academy находится продажа обучения. Эта студия создана самостоятельно по принципу работы, без копирования его материалов.

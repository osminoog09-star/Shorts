# M1lash Studio 2.0: сайт, радар новостей, разбор YouTube

Дата: 2026-10-28. Новая рабочая ветка: codex/m1lash-studio-dashboard-20261028.
Полный редизайн главной страницы motion-studio/index.html. Старый редактор сохранён в motion-studio/renderer.html; его Python рендер обновлён для отдельной страницы. Старые проекты и файлы не удалены.

## Что уже реализовано
1. Создание проекта: тема, описание, формат Shorts либо длинный 21+ минут, язык RU/EN, голос Дима/Света или тестовые оригинальные Орион/Нова, 9 официальных + 12 экспериментальных визуальных стилей, выбираемые роли агентов, источники.
2. Новости: каждое расписание 06:17 и 18:17 UTC (12 часов) GitHub Actions запрашивает конкретные публичные RSS NASA, TechCrunch AI, The Verge AI, MIT, IEEE Spectrum и Ars Technica; сохраняет короткие заголовки, прямые ссылки, время и происхождение в motion-studio/data/news.json, без выдуманных фактов. Если источники не ответили, данные помечаются и предыдущие публикации не стираются. Список можно фильтровать и переводить выбранную тему в Shorts одним нажатием. Системы GitHub Schedule могут задерживать запуск.
3. Разбор YouTube: принимает watch / shorts / youtu.be URL, проверяет video ID, создаёт в GitHub Issue заявку. После подтверждения владельцем Actions запрашивает публичные oEmbed метаданные; если есть разрешённый Gemini API, использует официальный YouTube video understanding для исследования речи и кадров, таймкодов, постановки, монтажа и оригинальных промптов. Не выдумывать покадровый аудит на основании только заголовка.
4. Агентские роли: исследователь, фактчекер, сценарист, режиссёр, художник, аниматор, звук, монтаж, аудитор, упаковка. Сам сайт браузерный, роли описываются в production_brief и agent_brief. Рабочие медиа-движки подключаются к следующему backend этапу.
5. Производство: список созданных GitHub Issues и переход к Actions. Заявка автоматически создаёт проверяемый исследовательский/производственный пакет после ручного Submit владельцем в GitHub. Получение готового MP4 в этом backend пока НЕ реализовано; исследовательский бриф не считается готовым роликом.
6. Переработанный мобильный интерфейс, сохранение черновика в localStorage без токенов и ключей.

## Настройка
- GitHub Pages Source: GitHub Actions. Сайт развертывается workflow Motion Studio · GitHub Pages после слияния изменений в main. Не утверждать доступность сайта без успешного деплоя.
- Для анализа самого публичного видео по YouTube-ссылке в репозитории Settings > Secrets and variables > Actions добавить Gemini API key как GEMINI_API_KEY и отдельно в Variables поставить M1LASH_VIDEO_API_ENABLED=true. Пока переменная выключена, анализ строится только по метаданным. Google API имеет собственные лимиты, доступность и тарификацию.
- Запуск производства: кнопка открывает форму GitHub Issue с метаданными, владелец подтверждает Submit. Действуют только заявки от владельца osminoog09-star с маркером M1LASH_JOB_START и строгой схемой; запуск чтения не даёт прав на публикацию YouTube.
- Не вводить в публичную тему приватные документы, секреты или личные видеофайлы. Все GitHub Issues публичны.
- Радар 12 часов в GitHub является самостоятельной RSS-лентой, он не импортирует автоматически результат существующей ChatGPT Automation. Существующая задача не менялась и не дублируется внутри ChatGPT.

## Реальный YouTube-анализ
Google Video Understanding: https://ai.google.dev/gemini-api/docs/video-understanding
Публичные YouTube URL поддерживаются официальным API, private/unlisted — нет. Автоматическая модель анализирует по выборке кадров и аудио, не гарантируя каждый кадр/слово. Данные и извлечённые техники проверяются человеком; нельзя копировать чужие кадры, сценарии, музыку и героев.

## Контроль выпуска
- Длинные ролики только от 21:00 (1260 секунд), предпочтительно 23–28 минут с содержательными актами, без затягивания.
- RU главный авторский голос Дима ru-RU-DmitryNeural; Света ru-RU-SvetlanaNeural второй голос. Оригинальные локальные Qwen персонажи без отдельного одобрения НЕ входят в опубликованные ролики.
- Минимум два независимых источника на каждый значимый факт; режиссёрский аниматик; аудит визуала/персонажей/аудио >=8/10 по каждой категории; лицензии и человеческое решение GO.
- Текущая верстка не публикует YouTube видео и не меняет существующие расписания.
- Компоненты Runway, Higgsfield, Canva, HeyGen, Descript, Adobe Express можно использовать как отдельные инструменты/плагины в ChatGPT Work, однако GitHub Pages НЕ вызывает эти ChatGPT плагины напрямую. Прямое подключение потребует безопасного backend и официальных API; затраты и права проверяются отдельно.

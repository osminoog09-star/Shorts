# AGENTS.md — студия коротких роликов M1lash

Инструкция для любого ИИ-агента (Codex, ChatGPT Agent, Claude), который делает ролики и публикует их
на YouTube-канал и в Instagram владельца. Читай целиком перед работой.

## Что это за проект

- Канал YouTube: **M1lash** (@m1lash93), Instagram: **m1lash93**.
- Формат: вертикальные Shorts/Reels 1080×1920, 20–40 сек, юмор про ИИ, роботов, нейросети, позже игровые фейлы.
- Языки: **русский — основной**, английский — дополнительный. Каждый ролик делается в двух версиях RU и EN.
- Мат разрешён и приветствуется там, где он смешной (без цензуры, без запикивания), но не в первых 3 секундах.

## Структура репозитория

```
studio/                 движок роликов (Remotion + Python)
  src/BotSeries.tsx     универсальный рендер эпизода по данным из JSON
  src/BotParts.tsx      роботы (hr, col, guard, boss, agent), кофемашина, лица, кружка
  src/Narrator2.tsx     главный герой (позы, липсинк, коробка на голову)
  src/Story2.tsx        общие компоненты: Appear, Key (кинетический текст), Card, Bokeh
  src/Icons3D.tsx       глянцевые 3D-иконки (робот, папка, корзина, тревога)
  src/*_series.json     сценарии эпизодов (генерируются из tools/*_data.py)
  src/*_tl.json         таймлайны озвучки (генерируются tools/bot_tts.py)
  tools/extra_data.py   ← СЮДА добавлять новые эпизоды
  tools/bot_tts.py      озвучка: голоса, мат, музыка, таймлайн, липсинк
  public/               звуки, музыка, зерно, озвученные реплики
videos/                 готовые mp4 — отсюда берутся публичные ссылки для публикации
```

## Установка (один раз)

```bash
cd studio && ./setup.sh
```

Нужны: Node 18+, Python 3.10+, ffmpeg, RHVoice (ставится скриптом на Linux), голоса Piper (качаются скриптом).

## Как сделать новый ролик

1. **Придумай сценарий.** Правила юмора:
   - Тема — горячая ИИ/робот/нейросети-новость или узнаваемая боль (работа, ИИ-агенты, роботы дома, соцсети).
     Перед сценарием поищи в интернете, что сейчас обсуждают.
   - Не повторяй старые шутки: «вы абсолютно правы», «переписал на Rust», «я здесь, чтобы…» — уже было.
   - Хук в первые 2 секунды, эскалация, неожиданный панчлайн в конце, вопрос в комменты.
   - 9–13 реплик, ~25–35 секунд. Реплики короткие, живые, разговорные.
2. **Добавь эпизод** в `studio/tools/extra_data.py` в список `EPS` (смотри существующие `x1`, `x2` как образец):
   - `id` — уникальный, например `x3`; `show` — крупное название на заставке; `title` — подзаголовок;
   - `end` — финальная плашка, `cta` — вопрос в комменты, `accent` — цвет, `names` — подписи говорящих;
   - `lines` — реплики: `who` (кто говорит), `pose` (поза героя), `punch` (наезд камеры), `text` {ru, en};
   - `vis` — визуальные элементы с привязкой к репликам (`from`, `fo` — сдвиг в кадрах, `to`, `toFo`).
3. **Озвучь:**
   ```bash
   python3 studio/tools/extra_data.py
   python3 studio/tools/bot_tts.py extra_series extra_tl x3      # x3 — id нового эпизода
   ```
4. **Проверь кадры** (обязательно смотри картинки глазами, ищи наложения текста):
   ```bash
   cd studio && npx remotion still src/index.ts ep-x3-RU out/check.png --frame=200
   ```
5. **Отрендери обе версии:**
   ```bash
   npx remotion render src/index.ts ep-x3-RU out/x3_ru.mp4 --codec h264 --crf 21
   npx remotion render src/index.ts ep-x3-EN out/x3_en.mp4 --codec h264 --crf 21
   ```
6. **Положи в `videos/`** (понятные имена, латиница), закоммить и запушь в `main`.
   Публичная ссылка: `https://raw.githubusercontent.com/osminoog09-star/Shorts/main/videos/<файл>.mp4`

### Справочник

- **who** (голос): `n` герой, `nr` герой «робоголосом», `nw` герой шёпотом, `hr`, `col`, `guard`, `boss`, `agent`,
  `old`, `colh`, `plumb`, `coffee`; `fx` — пауза со звуком (`sfx`: `growl`, `crickets`, `turn`, нужен `dur` в кадрах).
- **pose** героя: `rest`, `talk`, `point`, `facepalm`, `shock`, `shrug`, `laugh`, `deadpan`.
- **vis type**: `key` (крупный текст), `robot` (role, pos left/center/right, size, reveal+face), `stamp`, `sign`,
  `chips`, `captcha`, `calc`, `cup`, `growl`, `alarm`, `bg` (night/dark), `box` (коробка на голову героя),
  `coffee`, `lamp` (допрос), `db` (удаление базы с таймером), `backups`, `poem`, `scan` (HUD-рамка «УГРОЗА»),
  `pigeon`, `call` (входящий звонок), `fridge` (с замком `lockAt`), `nameplate`.
  Нужен новый элемент — добавь `case` в `BotSeries.tsx`.
- Раскладка: контент сверху (y 150–850), субтитры y≈860, герой снизу. Не ставь элементы на y 850–1000.

## Дополнительные инструменты (по желанию)

Основной конвейер выше работает без них. Эти можно подключить для качества выше:

- **OpenMontage** — https://github.com/calesthio/OpenMontage — агентная видеостудия (Remotion + генерация
  картинок/видео через API: FAL, OpenAI, xAI). Нужна, если хочешь сгенерированные нейросетью кадры вместо
  векторных персонажей. Ключи кладутся в `.env` OpenMontage, не в этот репозиторий.
- **VoiceStudio** — https://github.com/debpalash/VoiceStudio — локальная озвучка и клонирование голоса
  (OmniVoice, 600+ языков), бесплатная альтернатива ElevenLabs. Если доступна — используй её вместо Piper/RHVoice
  для героя: положи wav в `studio/public/...` и укажи путь в таймлайне (поле `file` реплики).
- **vidIQ** (коннектор) — подбор тегов и названий, тренды, статистика канала M1lash.
- **Metricool** (коннектор) — публикация и лучшее время, см. раздел «Публикация».

## Публикация (через Metricool)

- Metricool brand id: **7605462**, часовой пояс Europe/Tallinn. В одном бренде подключены YouTube и Instagram.
- Видео передаётся **публичной ссылкой** из `videos/` (raw.githubusercontent.com).
- **YouTube** (`providers: [{"network":"youtube"}]`): `youtubeData.type = "short"`, `privacy = "public"`,
  `category = "COMEDY"`, `madeForKids = false`, `isAiGeneratedContent = false`, 10 тегов.
  Название: `🇷🇺 …  #shorts` или `🇺🇸 … #shorts`. Описание: 1–2 строки + вопрос в комменты + 7 хештегов.
- **Instagram** (`network: "instagram"`): только RU-версии, `instagramData.type = "REEL"`, `showReelOnFeed = true`,
  5 хештегов.
- Время (по Таллину) — сначала спроси `getBestTimeToPostByNetwork`, по умолчанию:
  - YouTube RU: **16:00** (будни 15–17 — пик), второй слот дня 19:00;
  - YouTube EN: **18:00 по Нью-Йорку** (= 01:00 / 00:00 по Таллину, учитывай переход на зимнее время);
  - Instagram RU: **10:00** утром или **18:00** вечером.
- Не больше 2 RU-роликов в день на YouTube, 1 Reels в день в Instagram. Перед постановкой посмотри
  `getScheduledPosts`, чтобы не ставить два ролика в один слот.
- Если Metricool отвечает 502 — повтори один раз.

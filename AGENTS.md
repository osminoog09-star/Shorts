# AGENTS.md — студия коротких роликов M1lash

Инструкция для любого ИИ-агента (Codex, ChatGPT Agent, Claude), который делает ролики и публикует их
на YouTube-канал и в Instagram владельца. Читай целиком перед работой.

## Что это за проект

- Канал YouTube: **M1lash** (@m1lash93) — весь наш контент. Instagram **m1lash93** — только Whop-клипы.
- Формат: вертикальные Shorts/Reels 1080×1920, 20–40 сек, юмор про ИИ, роботов, нейросети, позже игровые фейлы.
- Языки: **только русский**. EN-версии **пока не делаем и не публикуем** (решение Дениса 23.10) — рендерим только `ep-<id>-RU`.
  Композиции `-EN` в движке оставлены на будущее.
- Мат разрешён и приветствуется там, где он смешной (без цензуры, без запикивания), но не в первых 3 секундах.

## Структура репозитория

```
studio/                 движок роликов (Remotion + Python)
  src/BotSeries.tsx     универсальный рендер эпизода по данным из JSON
  src/BotParts.tsx      роботы (hr, col, guard, boss, agent), кофемашина, лица, кружка
  src/Narrator2.tsx     главный герой (позы, липсинк, коробка на голову)
  src/Story2.tsx        общие компоненты: Appear, Key (кинетический текст), Card, Bokeh
  src/Icons3D.tsx       глянцевые 3D-иконки (робот, папка, корзина, тревога)
  src/*_series.json     сценарии эпизодов (генерируются из tools/*_data.py)
  src/*_tl.json         таймлайны озвучки (генерируются tools/bot_tts.py)
  tools/extra_data.py   ← СЮДА добавлять новые эпизоды
  tools/bot_tts.py      озвучка: голоса, мат, музыка, таймлайн, липсинк
  public/               звуки, музыка, зерно, озвученные реплики
videos/                 готовые mp4 — отсюда берутся публичные ссылки для публикации
```

## Установка (один раз)

```bash
cd studio && ./setup.sh
```

Нужны: Node 18+, Python 3.10+, ffmpeg, RHVoice (ставится скриптом на Linux), голоса Piper (качаются скриптом).

## Как сделать новый ролик

0. **Прочитай `STRATEGY.md`** — там текущая стратегия по данным отчётов. Она важнее общих правил ниже.

1. **Придумай сценарий.** Правила юмора:
   - Тема — горячая ИИ/робот/нейросети-новость или узнаваемая боль (работа, ИИ-агенты, роботы дома, соцсети).
     Перед сценарием поищи в интернете, что сейчас обсуждают.
   - Не повторяй старые шутки: «вы абсолютно правы», «переписал на Rust», «я здесь, чтобы…» — уже было.
   - Хук в первые 2 секунды, эскалация, неожиданный панчлайн в конце, вопрос в комменты.
   - 9–13 реплик, ~25–35 секунд. Реплики короткие, живые, разговорные.
2. **Добавь эпизод** в `studio/tools/extra_data.py` в список `EPS` (смотри существующие `x1`, `x2` как образец):
   - `id` — уникальный, например `x3`; `show` — крупное название на заставке; `title` — подзаголовок;
   - `end` — финальная плашка, `cta` — вопрос в комменты, `accent` — цвет, `names` — подписи говорящих;
   - `lines` — реплики: `who` (кто говорит), `pose` (поза героя), `punch` (наезд камеры), `text` {ru, en};
   - `vis` — визуальные элементы с привязкой к репликам (`from`, `fo` — сдвиг в кадрах, `to`, `toFo`).
3. **Озвучь:**
   ```bash
   python3 studio/tools/extra_data.py
   python3 studio/tools/bot_tts.py extra_series extra_tl x3      # x3 — id нового эпизода
   ```
4. **Проверь кадры** (обязательно смотри картинки глазами, ищи наложения текста):
   ```bash
   cd studio && npx remotion still src/index.ts ep-x3-RU out/check.png --frame=200
   ```
5. **Отрендери RU-версию** (EN пока не нужна):
   ```bash
   npx remotion render src/index.ts ep-x3-RU out/x3_ru.mp4 --codec h264 --crf 21
   ```
6. **Положи в `videos/`** (понятные имена, латиница), закоммить и запушь в `main`.
   Публичная ссылка: `https://raw.githubusercontent.com/osminoog09-star/Shorts/main/videos/<файл>.mp4`

### Справочник

- **who** (голос): `n` герой, `nr` герой «робоголосом», `nw` герой шёпотом, `hr`, `col`, `guard`, `boss`, `agent`,
  `old`, `colh`, `plumb`, `coffee`; `fx` — пауза со звуком (`sfx`: `growl`, `crickets`, `turn`, нужен `dur` в кадрах).
- **pose** героя: `rest`, `talk`, `point`, `facepalm`, `shock`, `shrug`, `laugh`, `deadpan`.
- **vis type**: `newsdesk`, `headline`, `rank`, `rocket`, `tv` (новости, см. ниже), `key` (крупный текст), `robot` (role, pos left/center/right, size, reveal+face), `stamp`, `sign`,
  `chips`, `captcha`, `calc`, `cup`, `growl`, `alarm`, `bg` (night/dark), `box` (коробка на голову героя),
  `coffee`, `lamp` (допрос), `db` (удаление базы с таймером), `backups`, `poem`, `scan` (HUD-рамка «УГРОЗА»),
  `pigeon`, `call` (входящий звонок), `fridge` (с замком `lockAt`), `nameplate`.
  Нужен новый элемент — добавь `case` в `BotSeries.tsx`.
- Раскладка: контент сверху (y 150–850), субтитры y≈860, герой снизу. Не ставь элементы на y 850–1000.

## Формат «Новости ИИ» (format: "news")

Ежедневный выпуск и недельный топ. Наш герой — ведущий в студии (`newsdesk` даёт студию, бегущую строку и стол
с логотипом «M1●НОВОСТИ ИИ»). Образец — эпизод `n1` в `studio/tools/extra_data.py`.

- **Только реальные новости** за последние 1–3 дня (ежедневный) или 7 дней (недельный): ИИ (модели, агенты, сбои,
  компании), космос (запуски, миссии, открытия), роботы, громкие технологии. Каждый факт проверь минимум по 2
  источникам, источник указывай в карточке `headline` (поле `source`) и в описании ролика.
- Факт подаётся точно, шутка — отдельной репликой после факта (реакция ведущего). Не выдумывай цитаты реальных
  людей и не приписывай им слова; не шути над трагедиями, болезнями и смертями — такие новости пропускай.
- Ежедневный: 3 новости, ~35–50 с; на каждую — `headline` (tag ИИ/КОСМОС/РОБОТЫ/ТЕХ, tagColor), 1–2 реплики фактов,
  1 реплика-шутка (`punch`), иногда визуал (`rocket`, `tv`, `robot`, `stamp`, `key`).
- Недельный («Новости ИИ за неделю») — **полное видео, НЕ Shorts** (решение Дениса 24.10): горизонталь 1920×1080,
  **10–15 минут**, премиальный 3D-стиль (движок `longform/antikythera`, правила `skills/vizavi-motion/SKILL.md`),
  голос — тот же, что у длинных видео (edge-tts ru-RU-DmitryNeural через workflow `TTS`). 7–10 главных новостей
  недели обратным отсчётом, на каждую — факты (≥ 2 источника), контекст «почему это важно» и шутка ведущего;
  главы с таймкодами в описании, источники и музыка (атрибуция) в описании. Папка `longform/weekly-news/<ГГГГ-Wнн>/`.
  Выход — **воскресенье 17:00** по Таллину, YouTube `type: video`. В правило частоты Shorts не входит; нарезки из него
  не делаем без отдельного решения Дениса.
- id: ежедневные `n<число>` (Shorts, 12:00), недельные — папка `longform/weekly-news/<ГГГГ-Wнн>/`. `show` ежедневных: «НОВОСТИ ИИ», `title` — дата.
- Новые визуалы: `newsdesk` (ticker {ru,en}), `headline` (tag, tagColor, text, source, top), `rank` (n),
  `rocket` (rain), `tv` (cleanAt).

## Формат «Ремейк тренда»

Берём ИДЕЮ/ФОРМАТ вирусного ролика про ИИ/роботов/технологии (найденного через vidIQ outliers/trending
или поиск) и делаем СВОЮ версию с нашими персонажами и нашими шутками. Запрещено: скачивать, вставлять,
перезаливать или «перерабатывать» чужое видео/аудио/картинки, копировать текст чужого сценария дословно,
использовать чужие торговые персонажи. Разрешено: тот же сюжетный приём, структура шутки, тема, тренд-формат
(«POV: …», «когда …», «ИИ vs человек …») — пересказанные своими словами и нарисованные нашим движком.
Видео NASA (public domain) можно использовать как фон в космических темах. id: `t<N>`.
В описании укажи «вдохновлено трендом» без ссылки на чужое видео.

## Слоты публикации (чтобы агенты не пересекались), время по Таллину

**Правило частоты (решение Дениса 24.10, нарушать нельзя):** не больше **3 Shorts в день** и минимум
**6 часов между ЛЮБЫМИ двумя Shorts**. Два Shorts в одно время — запрещено. Считай не только
запланированные (`getScheduledPosts`, только `draft:false`), но и **уже вышедшие** сегодня ролики
(vidIQ `vidiq_user_videos` / `vidiq_channel_videos`). Длинное видео (19:00) в это правило не входит.

**Исключение — ежедневные «Новости ИИ» (решение Дениса 24.10):** выходят **каждый день в 12:00** по Таллину,
всегда. На них правило частоты не распространяется: они не считаются в лимит 3 Shorts/день и не проверяют
6 часов до соседних роликов, а другие форматы не обязаны отодвигаться от 12:00. Только один выпуск новостей в день.
Недельные новости — теперь полное видео (не Shorts), см. «Формат „Новости ИИ“».

**Приоритет при споре за слот:** 1) нарезки из длинных видео → 2) мини-сериалы → 3) всё остальное
(скетчи). Ежедневные новости в споре не участвуют — у них свой слот 12:00. Младший формат никогда не занимает и не сдвигает старший —
он сам уходит на следующий день. Старшему формату можно передвинуть младший пост на свободный слот.

**Слоты по лучшему времени** (Metricool best time для канала: пик 16:00, затем 10:00; 22:00 слабый):

| Формат | YouTube Shorts |
|---|---|
| Нарезки из длинного видео (дни +1, +2, +3 после длинного) | **16:00** (лучшее время) |
| Мини-сериалы (серии) | 10:00 |
| Скетч (Daily AI short, пн–сб) | 10:00, если свободно; иначе следующий день |
| Недельные новости (вс) | **полное видео 10–15 мин, 17:00** — не Shorts, вне правила частоты |
| Новости дня (ежедневные) | **12:00 каждый день**, вне правила частоты (исключение) |

Ремейк тренда (Daily trend remake) **на паузе** с 24.10.

**Instagram m1lash93 — НЕ для нашего контента.** Это аккаунт под клипы Whop (Content Rewards).
Наши ролики (скетчи, новости, ремейки) идут ТОЛЬКО на YouTube. Никогда не ставь их в Instagram.

Если слот занят или уже прошёл — следующий день в тот же слот. Перед постановкой всегда `getScheduledPosts`.

## Визуальный стиль канала — ОБЯЗАТЕЛЬНО для всех агентов (решение Дениса 24.10)

Для **всех новых роликов** — полных видео и Shorts (нарезки, сериалы, скетчи, новости) — используй этот стиль дословно:

> Стиль — премиальный стилизованный 3D: упрощённые объёмные формы со скруглёнными краями, глянцевые и матовые
> материалы, мягкий студийный свет и контактные тени, пастельная палитра. Это графика, не фотореализм; камера плавно
> облетает объект, глубина резкости выделяет главное. Анимируй стилизованные объёмные формы в трёхмерном пространстве.
> Используй перспективу, мягкое освещение и осмысленное движение камеры.

- Движок стиля: `longform/antikythera/engine.js` + `kit.js` (Three.js). Вертикаль 1080×1920 — режим `?portrait`
  (`render.mjs --short <имя>`), подписи переносятся автоматически.
- Другие стили из курса vizavi сохранены в `skills/vizavi-motion/references/` только как справка — **не применять**
  без отдельного решения Дениса.
- Старые 2D-движки (Remotion BotSeries) — до перевода на 3D допускаются только для уже начатых серий; новые форматы
  делай сразу в 3D-стиле.

## Длинные видео «Инженерия древности в 3D» — ОБЯЗАТЕЛЬНЫЕ правила (решение Дениса 24.10)

Длинные видео делают по очереди два агента: **Claude** и **Codex/GPT**. Правила одинаковые для обоих.

1. **1 длинное видео раз в 3 дня.** Авторы чередуются: Claude → Codex → Claude → …
   Значит каждый агент выпускает своё длинное видео **раз в 6 дней**. Не выпускай вне своей очереди.
2. **Время выхода длинного:** 19:00 по Таллину, в день по календарю ниже.
3. **Нарезки Shorts из длинного:** 3–4 штуки, **только после** выхода основного видео, каждая минимум
   через **6 часов** после любого другого Shorts на канале. Слот нарезок — **16:00** (лучшее время) в дни +1, +2, +3
   после длинного. Нарезки — главный приоритет: если 16:00 занят младшим форматом, передвинь тот пост на 10:00/другой день.
4. Общее правило Shorts сохраняется: не больше 3 Shorts в день, ≥ 6 ч между ними.
5. **Не трогай чужой проект:** Claude не меняет файлы/посты Codex и наоборот. Каждый пишет в свою папку
   `longform/<тема>/`.
6. Перед постановкой — `getScheduledPosts`; если день по календарю занят (сдвиг, сбой) — сдвигай
   **весь** свой следующий выпуск, а не вставляй в чужой день.
7. Обновляй календарь ниже: отметь «вышло» и впиши свою следующую тему.
8. **Длительность 8–15 минут.** Делать максимально качественно: проверенные факты (≥ 2 источника на факт),
   полная раскадровка, просмотр каждой сцены и стыков перед выпуском, честные пометки «реконструкция».
9. **Общая очередь тем** (берёт следующую свободную тот, чья очередь; занятую тему сразу впиши в календарь):
   1) Антикитерский механизм (Claude, 24.10) · 2) Автоматы Герона: первый паровой двигатель и торговый автомат (Codex, 27.10) ·
   3) Римский бетон, который сам себя чинит · 4) Сейсмоскоп Чжан Хэна · 5) «Багдадская батарейка»: разбор мифа ·
   6) Чаша Ликурга: нанотехнология IV века · 7) Персидский яхчал — «холодильник» в пустыне ·
   8) Коготь Архимеда и зеркала: правда и легенда.
10. **Озвучка:** пока — нейросетевой голос (edge-tts через workflow `TTS`, голос ru-RU-DmitryNeural).
    Когда вернётся компьютер Дениса — переходим на локальную бесплатную озвучку на его ПК (VoiceStudio и др.);
    до этого не меняй голос между выпусками, чтобы канал звучал одинаково.

11. **Музыка — только разрешённая, с указанием в описании** (для обоих агентов, для ВСЕХ роликов — длинных и Shorts):
    Kevin MacLeod / incompetech.com (CC BY 4.0, грузить workflow `Music` → `media/music/`, атрибуция дословно из
    `media/music/<трек>.license.txt`), фонотека YouTube (вручную Денисом), либо своя процедурная музыка.
    Запрещены коммерческие треки, звуки TikTok/Reels, «no copyright» с чужих каналов. Подробно:
    `skills/vizavi-motion/references/music-and-license.md`.
12. **Перед работой над длинным видео прочитай `skills/vizavi-motion/SKILL.md`** и модули из него

### Как делать нарезки из длинного видео (обязательно для обоих агентов)

1. **Не кропать горизонтальное видео.** Перерендерить сцены вертикально 1080×1920 тем же 3D-движком
   (`?portrait`, `render.mjs --short <имя>`), камера и подписи перестраиваются под телефон.
2. Каждая нарезка 30–60 с, **одна мысль**: свой хук в первые 1–2 с (короткая новая озвучка или сильное начало сцены),
   целые сцены — не обрывать фразу, в конце аутро «Полная история — на канале» (озвучка + плашка).
3. Описание: 1–2 строки + «Полная история — в длинном видео» + **ссылка на длинное видео** (после его выхода) +
   атрибуция музыки + хештеги. Название своё, не как у длинного, без флагов.
4. Конфиг нарезок — `longform/<проект>/shorts.json`, сборка звука и таймлайна — `make_shorts.py`,
   рендер — workflow `Render long video` с входом `short`, склейка — `Join long video`.

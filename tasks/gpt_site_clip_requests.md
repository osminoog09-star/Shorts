# GPT: вкладка «Клипы» на сайте студии (решение Дениса 01.11)

Зачем: Денис видит на сайте, какие клипы нужны, и сам вставляет туда ссылку (Google Drive и т.п.) — без пересылки файлов в чат. Дальше всё автоматически.

1. **Данные:** `publishing/clip_requests.json` — список заявок: `id`, `film`, `scene`, `minute`, `why`, `for` (какой ролик/слот), `status` (`нужен` → `ссылка есть` → `скачан` → `собран` / `ошибка`), `link`, `note`, `updated`. Ты наполняешь его списком сцен из `tasks/gpt_week_45_plan.md` п. 1 (и каждое воскресенье).
2. **Сайт `site/studio/`:** вкладка «Клипы» (на телефоне — главный экран над «Роликами», с бейджем «нужно N»). Каждая заявка — карточка: фильм, сцена, минута, зачем; поле «ссылка» + кнопка «Отправить». Плюс кнопка «Свой клип» (ссылка + заметка). Запись — через GitHub-токен Дениса в браузере, как уже работают «Одобрить»/«Заливаем».
3. **После «Отправить»:** статус `ссылка есть` → автоматически запускается скачивание (`fetch.yml` во временный путь Actions, **фильм не коммитить**) → `movie-short.yml` собирает Short → статус `собран`, ролик появляется в «Ролики → ждёт ок». Ошибка (нет доступа к файлу, не тот язык, нет сцены) — статус `ошибка` с понятной причиной на карточке.
4. **Google Drive:** принимать обычную ссылку «Поделиться» (`drive.google.com/file/d/<id>/...`) и превращать в прямое скачивание; большие файлы — с подтверждением загрузки. Подсказка на карточке: «Доступ: все, у кого есть ссылка».
5. **Виджет:** строка «🎬 Нужно N клипов» и уведомление, когда появились новые заявки или клип собран/упал.
6. Проверка: на телефоне в тёмной и светлой теме, тест с реальной Drive-ссылкой на маленький файл. Запись в HANDOFF и урок.

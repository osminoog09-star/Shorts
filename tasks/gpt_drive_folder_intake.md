# GPT: одна папка Google Drive вместо ссылок на каждый клип (решение Дениса 01.11, заменяет поле ссылки в карточках)

Денис **не будет** давать ссылку на каждый ролик. Он кидает фильмы (целиком, с русским дубляжом) и любые клипы в **одну** папку Google Drive. Всё остальное — сами.

1. **Сайт, вкладка «Клипы»:** одно поле вверху «Папка Google Drive» (сохраняется один раз в `publishing/drive_folder.json`, доступ приватный через уже подключённый Google OAuth; раздача ссылки всем не нужна). Поля «ссылка» в каждой карточке — убрать. Карточка показывает статус: `нет фильма в папке` → `фильм найден` → `сцена найдена (мм:сс)` → `собран` / `ошибка: причина`. Вверху: «в папке N файлов · нужно фильмов M · не хватает: …» — чтобы Денис видел, что докинуть.
2. **Сканер папки** (workflow по расписанию раз в 2 ч + кнопка «Проверить папку» на сайте): список метаданных приватной папки через Google Drive API + `GDRIVE_REFRESH_TOKEN` в GitHub Secrets (без содержимого). Сопоставить файлы с заявками по названию фильма (рус/англ, год, транслит; неуверенно — спросить на карточке «это тот фильм?»).
3. **Поиск сцены сам:** скачать фильм во временное место Actions (не коммитить, удалить после), ASR по всему фильму (faster-whisper, кэш транскрипта по SHA файла в артефакте), найти сцену по ключевой реплике/описанию заявки и ориентировочной минуте; проверить русский язык (§8) и что обещанное действие есть (уроки 1–2). Вырезать с запасом и отдать в `movie-short.yml` → готовый Short приватно на «ок».
4. **Один фильм — много роликов:** из каждого фильма, кроме заявленной сцены, предложить ещё 2–3 сильные сцены по рубрике m1lash-studio §2б (карточки «предложено», Денис может не трогать — агент делает сам по сетке).
5. Денис добавляет законно полученные фильмы в свою папку — без повторной Google OAuth настройки; дальше сканирование и поиск сцен выполняются автоматически по расписанию. Уведомление в виджет: «в папке новый фильм» и «готово N роликов на ок».
6. Проверка на реальной папке с маленьким тестовым файлом; урок в m1lash-studio; запись в HANDOFF.

**03.11 уточнение по безопасности:** публичное право `anyone=writer` сейчас включено и опасно. Для нового приватного сканера оно не нужно; владелец может установить Restricted. ASR-проверка теперь также читает временно файл через Google Drive API по OAuth, а не `gdown` по публичной ссылке. Выполнены tests `41552475966`, сканирование реальной папки `41551952914`. HDRezka как внешний источник отдельно блокирует антибот-защитой, это не сбой Drive.

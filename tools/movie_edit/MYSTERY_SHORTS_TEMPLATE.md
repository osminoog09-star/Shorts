# M1lash • Универсальный шаблон кино-Shorts «угадай фильм»

**Статус:** обязательная схема для новых роликов после 28.10.2026; основной голос — Дима (`ru-RU-DmitryNeural`), второй — Света (`ru-RU-SvetlanaNeural`) в отдельных ролях. По ней делаем следующий ролик без повторной переписки про стиль/голос/титры.

## Конвейер в одну строку

**Цепляющая кинофраза → русская сцена (full screen 9:16) → кинетические субтитры → подходящая лицензированная музыка → утверждённый ведущий с лайком, подпиской, благодарностью → ТОЛЬКО самое последнее слово: название фильма, устно, тем же самым голосом.**

Выпуск остаётся загадкой до последней реплики. Визуально название фильма не появляется **никогда**.

## Звук/ведущий — самая частая ошибка прежних V1/V2/V3

**Нельзя:** старое CTA голосом Liam → последнее название голосом Димы, Piper или иным синтезатором; нужен единый новый дубль Димы. Свету использовать только для отдельного персонажа, не в финале автора. Имя «Дмитрий» в двух разных TTS-системах **не означает** единый голос.

**Можно:**
- CTA и последнее название оба синтезированы **одним** `ru-RU-DmitryNeural` с теми же настройками; обновлены виземы и мимика ведущего.
- CTA и название оба синтезированы **только Димой** (`ru-RU-DmitryNeural`) с одинаковыми настройками и обновлёнными виземами. Архивные Liam/Piper-голоса не использовать в новых выпусках.
- Один исходный голосовой дубль, где в конце по сценарию произносится название (лучшее акустическое совпадение).

Если нужная версия голоса недоступна, **черновик**, а не выдача подмены за готовый ролик. Голос проверяется и по ID, и реальным прослушиванием. После названия не произносить ни одной фразы. Музыку при последнем слове приглушить, под неё не прятать название. Не показывать название титром.

## Правильная экранная композиция

- Основная сцена фильма заполняет кадр целиком: 1080×1920, никаких звёздных полей/широкого блока по центру/чёрных полос.
- Для двух лиц — переставить фокус между говорящими (pan/reframe) по таймкодам.
- Фразы титров на безопасной высоте, не поверх глаз, с максимальным контрастом.
- Музыка развивается по смыслу: напряжение → кульминация → переход в фирменную тему Laeko на собственном финале. Всегда учитывать авторские права и реальную лицензию, атрибуцию в описании. Не выдавать наличие лицензии на музыку за разрешение на кино.

## Проверка перед сдачей

1. Заполни копию [mystery_release.example.json](mystery_release.example.json) и прогони `python tools/movie_edit/validate_mystery.py <копия>.json`. Валидатор отсеивает **текстовые** спойлеры и разный ID голоса.
2. Сверь **реальное содержимое** видео с манифестом: видео 9:16 full-screen, титры без фильма, ведущий как в эталоне, одни и те же интонации CTA и последнего слова.
3. Проверь видео на нескольких кадрах, декодирование, громкость/качество, оформление и музыкальные атрибуции. Секрет не должен быть виден в YouTube title/description/tags/hashtags/pin/thumbnail/filename/субтитрах.
4. Проверь происхождение исходника и лицензию на каждый аудиотрек. Если права не подтверждены — не утверждать «готово к публикации». Не использовать сокрытие названия для обхода Content ID.
5. Не публикуй без поручения и проверки занятого слота. В `HANDOFF.md` записывай статус и QA.

**Важно:** этот формат — именно кинозагадка, а не все Shorts канала: в новостях/обзорах могут действовать другие правила.

# Movie-edit Shorts M1lash — формат «угадай фильм» (утверждено 28.10.2026)

> **Приоритет:** актуальные решения владельца в `AGENTS.md` и `CODEX_NOTICE.md`.
> Старый эксперимент 25.10 («Скажи моё имя» и «Старикам тут не место») — технические примеры монтажа, **не шаблоны публикационной упаковки**. С 28.10 фильм нельзя раскрывать в публичных метаданных или на экране.

## Нерушимые правила

1. **Интрига до конца:** название фильма/сериала **только вслух, последняя звуковая реплика самого ролика**. Не показывать название надписью даже на финальной карточке. Не выводить перевод названия текстом в титрах; последние слова не дублировать субтитрами. Не указывать название в YouTube title, description, hashtags, tags, pinned comment, thumbnail, chapters, captions, public file name, другой публичной упаковке. Не использовать узнаваемые имена актёров/персонажей как скрытую подсказку в упаковке.
2. **Ведущий — единственный и один голос на весь финал:** наш утверждённый ведущий за столом с корректным липсинком, сначала **«Подпишись! И спасибо всем, кто досмотрел и поставил лайк»**, затем **самая последняя фраза — название фильма/сериала**. По запросу владельца: голос **Димы, как у самого ведущего**. **Никакой подмены голоса на другую модель для одного слова.** Если текущий утверждённый CTA был записан Liam, для названия нужен именно Liam; если хотим весь финал Дмитрием, заново озвучиваем **и CTA, и название** одинаковым DmitryNeural и синхронизируем виземы. Piper Dmitri ≠ Edge DmitryNeural ≠ Liam. Нельзя назвать версию окончательной с неидентичными голосами.
3. **Настоящий Shorts full screen:** весь киноряд 1080×1920, кадры заполняют экран; без горизонтального видеоблока, чёрных или декоративных полос сверху/снизу. Камера — кроп по героям и действию, динамический reframe/zoom при смене планов, никакого срезания лиц/объектов. Не превращать на 9:16 в «размазанное широкое видео посередине».
4. **Русскоязычная киноречь**, если выбран RU-выпуск; субтитры крупные, кинетические, синхронные с репликами, с контуром и безопасными отступами от интерфейса YouTube, без раскрытия названия.
5. **Саундтрек под сцену:** проверенная лицензионная композиция (для динамики допустим Kevin MacLeod «Interloper», CC BY 4.0, при атрибуции) или своя музыка. Сделать развитие, удар на кульминации и ducking под речь; никогда не глушить ключевую реплику. Музыку Laeko из фирменной темы использовать лишь в нашем авторском финале, проверив условия NCS и требования к кредитам.
6. **Авторские права:** исходник, дубляж и музыка имеют отдельный статус прав. Публичный источник видео и отсутствие названия в метаданных НЕ дают лицензии на фильм. Права/Content ID нужно проверить независимо; если правообладатель требует явный credit с названием фильма, не обходим это правило скрытием названия, а решаем конфликт до публикации.

## Процесс — повторяй для каждого нового фильма

1. Выбери эмоциональную сцену с захватывающими первыми 1–2 секундами, внутреннее название/источник запиши в **непубличный бриф**. Проверь, есть ли настоящий русский кинодиалог и условия повторного использования.
2. Расшифруй слова/тайминги: `faster-whisper` с word timestamps, проверь ASR вручную. Собери 30–45 с сюжетной кульминации (не растягивая пустотой).
3. Определи фрагменты `tools/movie_edit/edit.py`, кадрирование и `SHOTS`; рендер `base.py` в реальном 1080×1920. Проверяй лица/действие в 10+ разных местах. Для сцены 16:9 корректно переставляй кроп/пан по шотам, а не просто `pad`.
4. Наложи кинетические титры `final.py` / `kinetic.py` и эффекты по таймкодам **только до финального голосового раскрытия**.
5. Добавь звуковую дорожку через `audio.py`: русская речь, музыку с правами и динамикой, sidechain/ручной ducking, переход в фирменный финал, пики под безопасным пределом.
6. **Финал:** короткая оригинальная вставка `videos/m1lash_outro_short_ru.mp4` (утверждённый аватар, Liam, lip-sync, музыка) ИЛИ полностью пересобранная концовка `studio/src/EditOutro.tsx` в выбранном голосе. **Затем последняя отдельная реплика с названием, строго тем же voice ID и тембром.** Последний кадр — без названия текстом; допустима нейтральная картинка ведущего и логотип M1lash. Никакого дополнительного слова/звукового слогана после названия.
7. **Метаданные:** открой [MYSTERY_SHORTS_TEMPLATE.md](MYSTERY_SHORTS_TEMPLATE.md), заполни `mystery_release.example.json` отдельной копией и запусти `python tools/movie_edit/validate_mystery.py <манифест>.json`. В публичных полях нельзя указывать фильм даже английским/альтернативным названием. Не спойлерить year/cast/series/sequel.
8. QA: `ffprobe` показывает 1080x1920 / аудио; `ffmpeg -v error -i finished.mp4 -f null -` без ошибок; контрольные кадры 0/1/середина/кульминация/CTA/последний кадр; обязательно **послушать** весь ролик, в особенности совпадение голоса CTA и последнего слова; аудиопики, лица, клиппинг, орфография, отсутствие названия текстом.
9. Только после правовой проверки и QA выдавай ссылку на реально существующий MP4; до этого статус **черновик**, не публиковать/не занимать чужую клетку сетки без поручения.

### Запреты при генерации

- Не копировать финальную заставку прежнего фильма со старым названием, годом или чужим CTA.
- Не заменять недоступный выбранный голос «похожим» без явного решения владельца.
- Не оформлять Shorts заголовком с названием фильма ради SEO: для **этого формата** ставка на интригу и комментарии.
- Не выдавать синтетический пересказ или фанатский ремейк за кадр настоящего фильма.
- Не скрывать правообладателя для обхода YouTube Content ID.

### Наследие (только техпроцессы, не упаковка)

- ASR: `faster-whisper` (в раннем эксперименте small, модель собиралась из npm `@skillninja/shortmovie-telop-model-p0..p3`); `word_timestamps`.
- `edit.py` — `SEGMENTS`, `SHOTS`, `PHRASES`, `PUNCH`, `SHAKE`, `FLASH`.
- `base.py` — 9:16 по реальному центру лица, `zoom`, `crop` и цвет; `final.py` — кинетические титры; `audio.py` — звук, музыкальные акценты.
- `studio/src/EditOutro.tsx`, `studio/src/edit_outro.json` — исходные средства оформления/липсинка ведущего. Старые props показывали название крупно, поэтому для нынешнего формата **не показывать title-чипсы и другие раскрывающие надписи**.

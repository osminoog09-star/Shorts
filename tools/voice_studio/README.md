# M1lash Voice Studio v0.1 — свой генератор оригинальных голосов

**Статус:** реализованы инструменты и CPU-only тесты. Реальный нейросетевой синтез требует личного ПК с локальными проверенными весами Qwen3-TTS. Голоса НЕ заменяют обязательных Диму (ru-RU-DmitryNeural) и Свету (ru-RU-SvetlanaNeural) без отдельного одобрения владельца.

## Что создано
- voices.json: три придуманных голосовых персонажа RU/EN: Орион RU (теплый исследователь), Нова RU (научная журналистка), Орион EN (американский рассказчик).
- design: официальный Qwen3-TTS-12Hz-1.7B-VoiceDesign производит уникальный оригинальный образец reference.wav из описания тембра, а reference.json фиксирует SHA256, транскрипцию, происхождение и статус NOT APPROVED.
- narrate: официальный Qwen3-TTS-12Hz-0.6B-Base берёт наш оригинальный reference.wav, строит reusable create_voice_clone_prompt и озвучивает каждый фрагмент сценария. Выходы: line_0001.wav ... narration.wav ... manifest.json с хешами и текстом.
- Никаких автоматических загрузок библиотек, моделей и кодов из интернет-сайтов при запуске. Файлы с записями остаются приватно в work/voice_studio, публичный GitHub только для исходников.
- SHA-проверка образца, запрет перезаписи, отдельные режимы проверки без ИИ. Голос не получает ложный статус Димы/Светы.

## Технология
Официальный код Apache 2.0: https://github.com/QwenLM/Qwen3-TTS
Модель создания: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign
Модель повторного голоса: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base
Используем официальный способ Voice Design then Clone, а НЕ просто повтор одного промпта.

## Безопасная установка на свой NVIDIA ПК
1. Создай отдельное Python-окружение без доступов к YouTube/GitHub/Metricool и проверь официальную версию PyTorch, CUDA, qwen-tts и soundfile, лицензии и известные CVE.
2. Скачай модели ТОЛЬКО из официальных репозиториев Qwen Hugging Face, используя заранее проверенные commit revision и SHA256. Для каждого снимка файлы должны лежать в локальной директории с точным именем модели и config.json. В public Git эти файлы не загружаются.
3. Для GPU 12 ГБ проверяй потребление VRAM на одном коротком тесте. Это ожидаемо подходящий класс железа, но здесь не измерен.
4. Никаких сторонних автоматических setup.sh, неизвестных ComfyUI custom nodes, загрузки приватных голосовых образцов на чужие сайты, произвольных remote code исполнений.
5. Установка моделей на личный ПК пока НЕ выполнена, так что никакого заявления об оригинальной озвучке готового фильма сейчас нет.

## Использование
Список персонажей:

    python tools/voice_studio/m1lash_voice.py list

Создать наш голос — Орион:

    python tools/voice_studio/m1lash_voice.py design \
      --voice orion-ru \
      --model-dir /path/to/models/Qwen3-TTS-12Hz-1.7B-VoiceDesign \
      --out-dir work/voice_studio/orion-ru

Озвучить полноценный сценарий этим голосом:

    python tools/voice_studio/m1lash_voice.py narrate \
      --voice orion-ru \
      --model-dir /path/to/models/Qwen3-TTS-12Hz-0.6B-Base \
      --ref-dir work/voice_studio/orion-ru \
      --text-file scripts/my_long_script_ru.txt \
      --out-dir work/voice_studio/episode_001_orion

К обоим вызовам можно добавить --dry-run; он не загружает нейросеть, не создаёт аудио. Сначала проверяй качество 10 образцов: произношение имен, эмоции, артикуляция, темп, отсутствие выпадений слов, стабильный голос при разных репликах. Запускай над оригинальными или явно разрешёнными голосами. Изменение основного Димы и Светы — только отдельным решением владельца после прослушивания.

## Проверки
- Автоматические offline-тесты: python -m unittest discover -s tests -p 'test_m1lash_voice_studio.py' -v
- Объективный аудио-аудит: tools/voice_lab/wav_audit.py (в экспериментальной ветке Studio 2.0), плюс человеческое прослушивание обязательно.
- Длинный выпуск должен иметь оригинальный сюжет и реально подготовленный MP4 >=21:00, помимо качественной звуковой дорожки.

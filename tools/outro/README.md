# Фирменная концовка M1lash (утверждена Денисом 31.10.2026; ревизия 2 — после аудита Claude)

Готовые файлы — **не собирать заново для каждого ролика**, просто подклеивать в конец:
- `media/outro/m1lash_outro_v1_vertical.mp4` — Shorts 1080×1920, 5,0 с
- `media/outro/m1lash_outro_v1_horizontal.mp4` — длинные 1920×1080, 5,0 с

Что внутри: 3D-логотип «M1lash STUDIO» влетает, кнопка «ПОДПИСАТЬСЯ» нажимается на слове «Подпишись» → «ВЫ ПОДПИСАНЫ ✓», «СПАСИБО, ЧТО ДОСМОТРЕЛ!» на слове «спасибо», лайк выпрыгивает на слове «лайк». Голос — Дима с живой подачей (`media/tts/outro_universal/cta.mp3`, «Подпишись! И спасибо всем, кто досмотрел и поставил лайк.»), щелчок и «поп» — синтез ffmpeg.

Кино-Shorts (AGENTS §8): после концовки Дима одной фразой называет фильм («Это был фильм… X») над последним кадром карточки — последние слова ролика = название.

Перерендер (если Денис попросит правки): `outro.html` (анимация, тайминги B0/PR/TH/LK под слова голоса) + `render.js` (Playwright, кадры 30 fps) → ffmpeg с голосом (смещение 0,3 с). Нужны three.min.js r128, `site/studio/i/font.json`, шрифт Unbounded cyrillic/latin 800.

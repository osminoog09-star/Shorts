## Воспроизведение и QA

python3 episodes.py → jobs/tts/research_codex.json → TTS → prepare.py <id> → Rhubarb → esbuild film.tsx → render.mjs <id> → finish.py <id>.

Рендер: GitHub Actions Codex research Shorts batch, пять независимых матричных заданий. Каждый сохраняет ровно свой MP4 и QA. Готовность = успешный полный decode, проверка кадров/стыков и описания + визуальная оценка. Контактный лист не доказывает непрерывный просмотр/прослушивание; такие проверки не заявлять без инструмента. Метрики и YouTube ID не выдумывать. videos.csv: pending ID пустой до выхода, метрики пустые. Расход tokens — оценка с ~; видIQ = 0; фактические render_min из Actions.

В learnings нет выводов средней/высокой уверенности: применены только явно утверждённые правила первого кадра/одной мысли; сравнительное превосходство стиля остаётся гипотезой. Новых версий исходных промптов не вводим, prompt_lab не заполняется фиктивными результатами. Пять разных тем/стилей не позволяют приписать различия именно стилю.

## Фактически выбранный способ экспорта

Новый workflow не запущен: автоматическая проверка отклонила добавление конвейера с записью в main без более явного разрешения. Его исходник остаётся локальным предложением, не частью опубликованного решения. Сборка переведена на локальный native Canvas2D (@napi-rs/canvas), те же функции анимации из film.tsx. Render-native.cjs не использует браузер или удалённую автоматику. Персонаж появляется в утверждённой финальной вставке 5,8 с, остальное время — полноэкранная анимация с закадровой речью. Нового видимого говорящего в основном рассказе нет; оригинальный Rhubarb в финале сохранён. Калькулятор проверен исполнением настоящего скрипта calculator.html (три входных примера), не тестом браузерного UI.

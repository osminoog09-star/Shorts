# Laeko × M1lash — музыкальная демка ведущего

Локальная проба по просьбе Дениса 25.10.2026. Не публикация и не изменение готовых роликов.

12 секунд, 1080×1920, 30 fps, H.264/yuv420p + AAC. Утверждённый Narrator2 и карточка за столом взяты из студии; это новый монтаж, исходные проекты Claude не изменялись. Новая речь не генерировалась, речевой липсинк не добавлялся; проба оценивает музыку/выход ведущего/CTA.

## Монтаж

Выбран источник 00:42.610–00:54.610; сильные амплитудные атаки измерены из официального MP3 (это не человеческое прослушивание).

- 0–1.50: подготовка появления, «Секунду…».
- 1.50: музыкальная атака 44.110 исходника, выход карточки, «А вот и я».
- 4.892: реакция «Досмотрел?» (47.502 исходника).
- 6.139: кнопка подписки (48.749 исходника).
- 9.521: благодарность (52.131 исходника), затем вопрос.
- 11.60–12: общий fade out.

Варианты рассматривались: статичный логотип / ведущий на весь экран / утверждённая карточка с выходом под сильный удар; выбран последний. Для CTA: резкая вспышка / нажатие-палец / мягкий pop; выбран pop без вспышек. Фон — многослойная тёмная студийная графика для изолированной оценки заставки, не замена сценам основного выпуска.

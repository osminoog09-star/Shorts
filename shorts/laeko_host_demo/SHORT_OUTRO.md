# Короткий финал для следующих Shorts — 25.10.2026

Денис одобрил предложение: обычно 30–45 с истории и 5–6 с говорящего финала, без растягивания ради жёсткого минимума.

Готовый отдельный ресурс: `videos/m1lash_outro_short_ru.mp4` — 5.8 с, 1080×1920/30fps H.264/yuv420p, AAC. Это монтажный ресурс, не отдельный пост.

Сохранена вся реплика существующего Liam: «Подпишись! И спасибо всем, кто досмотрел и поставил лайк», Rhubarb-липсинк и карточка ведущего. Удалены 1.5 с ожидания и длинный музыкальный хвост первой демки. Демо-вопрос заменён на общий вопрос для комментариев; в итоговом выпуске адаптировать к его теме. После речи музыка поднимается. Длинные видео могут использовать расширенный финал, с адаптацией композиции в 16:9.

Финальный клип: `short_outro.tsx`, `short_outro.html`, `render_short_outro.cjs`, `make_short_outro.py`.

Сборка: esbuild short_outro.tsx → short_outro_bundle.js; node render_short_outro.cjs; python3 make_short_outro.py. Локальные исходные MP3 не коммитить, источники указаны в README и VOICE_DEMO. Время Liam source = 20 + local seconds, музыка source = 44.110 + local seconds. Голос без изменения скорости/обрезки слов. Музыка коэффициент 0.18 под речью, подъём 4.55–5.25 с, fade 5.55–5.8 с.

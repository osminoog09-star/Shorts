# Пёс просит второй ужин — реалистичная проба

25.10 Денис отклонил мультяшного пса и явно выбрал реалистичного, как на обычной съёмке. Старый dog_big_stick не использовать для выпуска. Новая идея: пёс, которого только что покормили, снова приносит пустую миску.

Статус: опорное изображение сгенерировано встроенным imagegen; фотографический стиль, естественные пропорции. driver — исключительно собственная процедурная анимация движения, не финальный видеоряд.

Для пробы движения выбран бесплатный Genjutsu motion-control (1 доступный запуск, максимум 720p). Использовать только use_free_gens:true; при отказе не переключать на оплачиваемые кредиты. Оплачиваемый баланс Higgsfield не тратить. Runway требует повторной авторизации, не использован.

Никакой автопубликации: ролик в запасе, только после отдельного решения Дениса. Голос не подменять; Liam пока недоступен по лимиту.

Собственные исходники и звук. Ни чужой видеоряд, ни чужое аудио не используются. Опорная картинка — синтетическая, не документальная съёмка собаки.

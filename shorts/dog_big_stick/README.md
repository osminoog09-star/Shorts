# Пёс, палка и ИИ-помощник

Оригинальный вертикальный 3D-скетч, RU, 22 секунды. Вдохновлён распространённой ситуацией «собака и слишком большая палка», а не чужим сценарием. Чужие кадры/аудио не используются.

Референсы ситуаций: https://video.storyful.com/record/38532 ; https://video.storyful.com/record/1094 . Самостоятельный панчлайн: робот расширяет дверной проём вместо поворота палки.

Проба первого риска — узнаваемость/симпатичность пса, движение лап/хвоста и контакт палки с дверью. Источник модели и анимации: film.js. Для первого теста — собственные SFX и музыка, без синтезированного диктора: Liam требует минимум 14 кредитов, доступен 1. Голос молча не заменять.

## Раскадровка до рендера

| Время | Три варианта → выбор | Действие, камера, ритм |
|---|---|---|
| 0–3 | Пёс с палкой / палка из лифта / палка поверх машины → пёс у двери | Лапы и хвост двигаются, палка поперёк; камера в три четверти из дома; короткий хук |
| 3–5 | Удар / виноватый взгляд / примерка боком → мягкий удар и наклон головы | Палка упирается в косяк, отскок; деревянный тук и пауза |
| 5–9 | Хозяин / робот / умная дверь → робот | Боковой въезд робота, смена крупности; электронный сигнал |
| 9–13 | Поворот палки / распил / расширение проёма → расширение | Два косяка разъезжаются, инструмент; механический треск и свист |
| 13–18 | Пёс убегает / робот гордится / пёс проходит с трофеем → проход | Пёс идёт на камеру; оплачен весь абсурд; музыкальный акцент |
| 18–22 | Лай / вопрос / спасибо → спасибо и вопрос | Удержать финальную композицию, подписка и вопрос |

Это рабочая визуальная проба. Полный выпуск должен получить одобренный голос, ведущего HostCorner с виземами и повторную проверку; тест не ставить на публикацию.

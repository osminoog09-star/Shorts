## Две оригинальные рисованные истории

1. ИИ-пылесос выселяет хозяина: уборка → носки → кресло → телевизор → хозяин признан «беспорядком» → робот закрывает дверь. Шесть разных предметных сцен, двенадцать фраз Димы.
2. Почему попкорн взрывается: зерно → вода/крахмал → давление → оболочка лопается → крахмальная «ножка» подпрыгивает → готовый попкорн. Шесть предметных сцен, двенадцать фраз Димы.

Механика: SVG/HTML+Playwright, 1080x1920 30fps, safe areas, без PIL-сцен и без ведущего в окне, S1-D25 2D. После 6 стопов и просмотра — Дима через Edge TTS, движение, утверждённая концовка, штатные check.py/look.py/decode. По итогам каждого файла отдельный коммит.

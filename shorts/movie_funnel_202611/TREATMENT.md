# Два кино-Shorts: S6-D25, производственный пакет

**Статус: BLOCKED_SOURCE.** Нет русских киноисходников, поэтому это не готовые ролики. Сценарий и упаковка утверждены к самостоятельной разработке. Оба Shorts должны быть собраны раньше длинного. Название фильма нигде не выводится на экран и в публичные поля: оно звучит только последними словами Димы.

## A — сделка, которая не работает

Внутренняя сцена: Карсон Уэллс пытается предложить деньги/выход, Чигур меняет рамку разговора. Не повтор старого опубликованного Shorts с монетой.

Одна мысль: собеседник пытается найти цену, а противник не принимает саму идею обмена. Не делать универсального утверждения, что Чигур никогда не совершает сделок.

| Отрезок, плановый бюджет | Кино/наш вклад | Действие и звук |
|---|---|---|
| 0–2 с | Русский диалог: сразу попытка сделки | Начать с сильной реплики из фактического дубляжа; точные слова/in/out ещё не выбраны. Не вставлять приветствие. |
| 2–12 с | Два собеседника, настоящий монтаж сцены | Reframe между лицами по говорящему; слова в нижней безопасной зоне, золото на смысловом акценте. Не имитировать чужую монтажную последовательность. |
| 12–24 с | Возражение/смена рамки | Перспективный слой ключевого слова выходит чуть вперёд на реплике, камера фона движется слабее. Не трясти каждое слово. |
| 24–34 с | Реакция и нерешённая угроза | Дать паузе прозвучать; музыку убрать перед ответом. Не добавлять выстрел из другой сцены и не подменять порядок событий. |
| около 34–47 с | Свой финал | HostCorner, новый липсинк; единый дубль Димы. Вопрос и устное название. Название на экран/в captions не попадает. |

Варианты хука: (1) предложение денег **выбран** — событие и конфликт; (2) общий план коридора — слабее без контекста; (3) авторское вступление — отвергнуто, задерживает сцену. Варианты реакции: взгляд / телефон / графика весов — выбрать настоящий взгляд; телефон только если в выбранном непрерывном фрагменте. Варианты финала: карточка / герой на весь экран / ведущий в углу — выбран ведущий в углу.

Контраст энергии: 7 → 5 → 8 → 2 (пауза) → 5. Не делать трейлерный взрыв и белые вспышки. Склейки на речевых границах; смысл важнее музыкальной сетки. Самый сложный план — переключение между двумя лицами при узком кропе: проверить по реальным кадрам до остального монтажа.

## B — отказ от навязанных правил

Внутренняя сцена: финальный разговор Карлы Джин с Чигуром, она не принимает предложенную рамку монеты. Это не новый монтаж прежней заправки.

Одна мысль: отказ назвать сторону заставляет увидеть человека, принимающего решение. Не выдавать сцену за совет, гарантирующий спасение, и не изображать её судьбу противоположно фильму.

| Отрезок, плановый бюджет | Кино/наш вклад | Действие и звук |
|---|---|---|
| 0–2 с | Настоящая русская реплика отказа | Начать с отказа, не с вида дома; если для смысла требуется предложение Чигура, дать его первым очень коротко. Выбрать по исходнику. |
| 2–14 с | Ответ Чигура | Читаемые фразы по реальному дубляжу; лица целиком. Лёгкий параллакс между фразой и кинорядом. |
| 14–27 с | Карла возвращает ему ответственность | Не выдумывать цитату: точные субтитры только после прослушивания источника. Пауза без музыки перед главной фразой. |
| 27–34 с | Ответный взгляд | Развязка мысли, а не монтаж отсутствующего убийства. Без графического насилия. |
| около 34–47 с | Свой финал | Тот же Дима и HostCorner; вопрос зрителю; последнее устное название. |

Варианты хука: (1) отказ **выбран**, (2) монета на ладони, (3) плашка про правила. Варианты визуальной кульминации: весь диалог с титрами / перемещающееся ключевое слово / взрывная типографика — выбрана сдержанная фраза с одним выделенным словом. Варианты конца: обувь / авария / прямой взгляд — выбран взгляд; не смешивать финальный разговор с чужой временной последовательностью.

Контраст энергии: 6 → 4 → 7 → 1 → 5. Геройский момент — спокойный отказ, поэтому не иллюстрировать его победной музыкой. Первый кадр содержит лицо/действие, не чёрный фон.

## Общая реализация

- 1080×1920, 30 fps, H.264/yuv420p + AAC, full bleed. Dynamic reframe по реальным планам; не центральный кроп всего диалога.
- Две гарнитуры максимум; слова синхронны с услышанной репликой. Нижние ~380 px и правый интерфейс YouTube свободны. Титры не пересекают глаза.
- Ведущий — точная копия `studio/src/HostCorner.tsx` с собственными props этой папки, без изменения props чужих проектов. `host/HostCorner.tsx`; `host/index.tsx` — прозрачный кодовый overlay, не целое видео.
- `audio/end_a.mp3` — полученный TTS Димы, оригинальная длительность 13.392 с; полный CTA, вопрос, устное название. `audio/end_a_visemes.json` — Rhubarb phonetic. `audio/end_b.mp3` — отдельная концовка B, получена и сохранена в успешном TTS run 41116949032 после восстановления конфликта старого повторного запуска. Для неё рассчитаны собственные `end_b_visemes.json`. Иной голос не подставлялся.
- Ориентир 30–35 с истории + фактический финал; не ускорять кино и речь ради цифры. При удалении длинных TTS-пауз пересчитать фактические word timestamps и виземы, не просто сдвинуть рот вручную.
- Музыка — Kevin MacLeod с подтверждённым license-файлом и дословным credit; если недоступна, согласованная процедурная подложка. Оригинальная музыка фильма не считается отдельно лицензированной для наших вставок.
- Каждый самостоятельный экспорт проходит decode, кадры всех стыков/кропа, прослушивание, проверку титров и `validate_mystery.py`. До получения/прослушивания кино данные QA = pending.

# M1lash Мульт · voice cast / trial status

Владелец 04.11 утвердил: **МИЛ (главный герой) — только голос Дениса**, все остальные персонажи — **разные** разрешённые синтетические тембры. Основной источник AGENTS.md §3а.

| Роль | Engine | Speaker | Статус |
|---|---|---|---|
| МИЛ | локальная Qwen3-TTS 12Hz 0.6B Base | denis-qwen3tts-reference-v1 | приватный исходник владельца; в cloud runner нет локальных весов, VOICE_BLOCKED |
| АКС | Silero v5_cis_base_nostress (проектный кандидат) | audition: `ru_tat_marat`, `ru_bak_alfia` | **не прослушано, не утверждено** |
| Любые другие | отдельно определяем и тестируем | unique speaker | не смешивать голоса ролей |

Почему не Piper «Ruslan»: у него по MODEL_CARD исходного корпуса ограничения non-commercial, а для M1lash цель — будущая монетизация. Вместо этого см. официальный Silero [README](https://github.com/snakers4/silero-models/blob/master/README.md) (V5 CIS Base) и [LICENSE_CIS](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS) (MIT). Эти модели поддерживают ru_ префикс у кандидатов, но всё равно требуется реальная проба произношения, эмоций, тембра и явная фиксация движка/весов/версии.

**Аудиотест:** ровно две разные короткие реплики из episode.json, 24–48 kHz WAV, сравнить с голосом МИЛа на тихой музыке, проверять ударения и «не робот-пластилин». Доступ к модели на PC либо в разрешённой среде без оплаты. Не использовать чужой voice clone и не пушить личные образцы/финальные аудиодорожки Дениса в public GitHub.

Первый visual pilot **без звука**: никаких фальшивых WAV, нет речи персонажей и approved outro. Это не основание для публикации.

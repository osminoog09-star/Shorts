# «Нейроофис» — проверка короткого кодового ролика с голосом Димы

Выпуск-демонстрация: ИИ-директор составляет график смен. Звук собран из **уже готовых** реплик проекта (не используется эмуляция eSpeak/Piper/Liam). Метаданные TTS: jobs/tts/research_codex.json и jobs/tts/host_demo.json: `ru-RU-DmitryNeural`, rate `+8%`. Видеоряд (не статичные картинки) рендерится каждый кадр Python/Pillow, 1080×1920, 24fps; вертикальный оригинальный клип.

⚠️ Это **черновое демо** для просмотра, не финальная первая серия 21+ минут. Голос — Дима; ИИ говорит не отдельным голосом Светы, поскольку здесь повествование Димы. При сборке не запускать никакой API-публикации.

Артефакт workflow `Neurooffice RU voiced short demo · no publish` содержит MP4, 7 кадров QA и JSON. Все 7 сцен озвучены заранее записанными репликами из скетча о графике смен. Арт и mouth movements требуют художественного просмотра (времена слов ≠ точный phoneme lip-sync). Перед использованием как публичного Shorts проверить права и готовность аудио/CTA, читать AGENTS.md.

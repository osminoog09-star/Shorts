# huashu-motion · установка M1lash

Решение владельца 28.10.2026: дальнейшие ролики делать по оригинальному huashu-motion.

Оригинал: https://github.com/alchaincyf/huashu-motion (автор Huashu / 花叔, GitHub alchaincyf).
Установленная версия: 0.3.1, закреплённый upstream commit `52467f99c602b76ba86d511d37acdfe93fa1e16e`.

## Подготовка на новом компьютере или GitHub Actions

```sh
git submodule update --init --recursive skills/ext/huashu-motion
./scripts/huashu-motion doctor
./scripts/huashu-motion templates
```

Оригинальный SKILL.md: `skills/ext/huashu-motion/skills/huashu-motion/SKILL.md`.
Подключения для агентов: `.agents/skills/huashu-motion` и `.claude/skills/huashu-motion`.
CLI вызывает только закреплённый код, не скачивает произвольную latest-версию через npx.
Node >=22, FFmpeg/ffprobe и Chrome/Chromium/Edge. Для браузера вне стандартного пути: `OM_CHROME=/absolute/path/to/chrome`.

## Как применять к нашим выпускам

1. До реализации читать оригинальный skill, director.md, rhythm.md и подходящий motion language; собрать реальные проверенные материалы и права.
2. `treatment.md`: одна мысль, динамическая раскадровка, кривая энергии, четыре ключевых кадра, действия и переходы. Пользователь разрешил выбирать направление самостоятельно; не повторять анкету перед каждым шагом.
3. Сначала самый сложный план, затем пилот, `om check`, просмотр кадров и нормального воспроизведения, исправления, полный экспорт и `om qa`. Зелёный инструментальный check не равен художественному одобрению.
4. Код HTML/GSAP/Canvas/Three.js, один paused timeline, детерминизм по времени, локальные зависимости, стабильные data-om-id и редактируемые переменные. Не превращать длинный выпуск в растянутый 30-секундный шаблон.
5. Голос канала остаётся **ru-RU-DmitryNeural**, Света разрешена для своих ролей. `om voice` с системным/Kokoro-голосом не использовать для автоматической замены. Импортировать готовую озвучку и её фактические тайминги.
6. Ведущий **M1lash Narrator2/HostCorner** сохраняется. Персонаж «bean Huashu» не лицензирован для нашего использования; из демонстраций его не переносить.
7. Новости: >=2 источника на факт; даты публикации и события различать; условные схемы/реконструкции подписывать; основной longform MP4 >=21:00 и duration gate. Shorts отдельно, вертикальная перевёрстка, не кроп.
8. Условия AGENTS.md о голосах, материалах, качестве и публикации продолжают действовать. huashu-motion задаёт метод режиссуры и производства, не отменяет эти ограничения.
9. Ничего автоматически не публиковать, не менять готовую очередь/чужие проекты. Результат установки не означает, что текущий новостной MP4 завершён.

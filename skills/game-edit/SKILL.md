## 2. Монтажный лист (ep1.py)
- Сегмент: `a`,`b` (глобальное время сессии), `k`: n обычно · f ускорено (звук ×0.5) · m ускорено без звука под музыку · s слоумо · card карточка (`bg=` размытый кадр).
- Опции: `zoom`, `zin`, `freeze`, `frsfx`, `bright` (тёмные ночные сцены 0.05), `sp`, `cap` [(«@0:28:49.1», длит, текст, стиль)], `sfx`, `trk` (трек NCS).
- **Длина серии 6–10 мин, название с поиском (решение Дениса 26.11):** серии 12–23 мин получили 0–3 просмотра — у канала нет постоянной аудитории, вход только через поиск. Название начинается с игры и поискового запроса («Wardogs — …», «Active Matter: …» + понятная суть), шутка во второй половине; превью — одна эмоция и 2–4 слова. Отчёт: `reports/weekly/2026-W48.md`.
- Структура серии: **хук 25–30 с** (3 лучших момента, без мата в первые 3 с) → карточка-название → главы «ГЛАВА N · …» по матчам → итоговая карточка-шутка.
- Титры — вручную по пословной расшифровке, только реплики-панчлайны (стиль sub/subbig), без автосабов.
- Звук сводим сами: Game + Mic×1.4 + Discord×2.2 (в OBS-Mix друзья тихие).
- **Аудит перед сдачей** (`python audit.py` → по 3 кадра на сегмент): вырезать экраны смерти/респауна/«до возрождения» (чёрные), пустые прогулки ускорять ×3, длинные виды с вертушки резать и подписывать контекст («я за штурвалом — пацаны воюют внизу»). Это то, что Денис назвал «странные моменты».
- Сегмент не должен пересекать стык 30-минутных файлов OBS (assert в edit.py) — делить на два.

## 4. Музыка — NCS, **под сцену, а не один жанр** (решение Дениса 18.11)
Источник: **https://ncs.io/free-music** (NoCopyrightSounds; бесплатно для YouTube/Shorts, нужен кредит; спонсорка/реклама — только с лицензией).
- **Главное правило:** трек подбирается под настроение конкретной сцены/главы, жанр — любой. Фонк — не правило, а один из вариантов (в Wardogs взяли его только потому, что сцены были агрессивные/мемные).
  Сначала описать сцену одним словом (напряжение, погоня, перестрелка, фейл/кринж, смешной диалог, полёт/пейзаж, грусть/поражение, победа, стройка/лут), потом искать по настроению.
- Карта «сцена → настроение NCS (`&m=`) → жанры (`&g=`)»:
  | сцена | настроение | жанры-кандидаты |
  |---|---|---|
  | подкрадывание, ночь, снайперы | Suspense, Sneaking, Mysterious, Dark | Midtempo Bass, Trap, Witch House |
  | перестрелка, штурм, оборона | Heavy, Angry, Epic | Dubstep, Drumstep, Phonk, Neurofunk |
  | погоня, езда, вертушка на скорости | Chasing, Running | Drum & Bass, Phonk, Future Bass |
  | полёт, пейзаж, затишье | Floating, Dreamy, Peaceful | Chill Bass, Liquid, Melodic House |
  | фейл, кринж, смешной войс | Quirky, Eccentric, Happy | Brazilian Phonk, Glitch Hop, Electro House |
  | поражение, «ну конечно» | Sad, Sentimental | Chill, Ambient, Lofi |
  | победа, удачный момент | Euphoric, Epic, Hopeful | Future House, Melodic Dubstep, Hardstyle |
- Фильтры в URL: `?m=<настроение>&m=<…>` + `&g=<жанр>` + `&vocals=none` (без вокала под речь) + `&sort=pop`. Комбинировать 2 настроения = «или».
- Избегать заезженных хитов (Mortals Funk, Royalty Funk, Sky High…) — брать треки со 100 тыс.–2 млн прослушиваний. Под речь друзей — только инструментал.
- Скачивание (официально): `curl -L -o media/music/ncs/<slug>.mp3 https://ncs.io/api/download/<slug>` (slug = путь страницы трека, напр. `ncs.io/bane` → `bane`). Файлы в git НЕ коммитим (см. `media/music/ncs/README.md`).
- Кредит в описание — на каждый трек:
  ```
  Track: <Artist> - <Title> [NCS Release]
  Music provided by NoCopyrightSounds
  Free Download/Stream: http://ncs.io/<slug>
  ```
- Трек на главу/сцену: `TRACKS` в ep1.py по глобальному времени или `trk=` прямо в сегменте (для отдельной сцены внутри главы). Музыка только в m/f-кусках и тихой подложкой в Shorts; трек продолжает играть с места остановки.
- Claude треки не слышит — честно говорить, подбирать по жанру/настроению/популярности; если Денис бракует — предложить ему самому выбрать на ncs.io.

## 5. Сборка и QA
1. `python ep1.py --dry` (длина) → `python ep1.py` → `python shorts.py` (части кэшируются по сигнатуре; `_eng` в edit.py поднимать при смене рендера).
2. `local_jobs.py finish --body … --out C:\M1lash\Готово\…\x.mp4 [--vertical]` → концовка v7 + check.py.
   - **NO-GO пик тела > −1 dBTP**: finish сам линейно выравнивает до −15 LUFS, поэтому важен запас пик/громкость. Если пик только в первые 0,1 с — это AAC на старте: `afade=t=in:d=0.2` по телу. Общий случай — `alimiter` на 192 кГц + `-aac_coder twoloop`.
3. Превью 1280×720: кадр-доказательство + 2 строки Impact (жёлто-голубой + белый), `format=rgb24` (jpg из yuv ffmpeg не пишет).

## 6. Заливка (только после «ок», PRIVATE без даты)
- Манифесты: `make_manifests.py` → `publishing/queue/<id>.json` (category 20 «Игры», `contains_synthetic_media: false`, теги игры).
- Серия > 2 ГБ не пролезает в draft-релиз GitHub — пережать `h264_nvenc -b:v 10M -maxrate 14M` (≈1,7 ГБ на 23 мин), звук `-c:a copy`.
- `local_jobs.py publish` делает `git pull --rebase` локального репо — если локальный `main` разошёлся с origin (чужие коммиты), он падает. Обход (`upload.ps1`): `git worktree add --detach <tmp> origin/main` → cherry-pick только своих манифестов → push → `gh workflow run youtube-direct.yml -f mode=upload` → `gh run watch` → удалить draft-релиз. Чужие untracked-файлы — переносить в `C:\M1lash\private\backup_untracked_<дата>`, не удалять.
- Скрипты .ps1 с кириллицей сохранять **UTF-8 с BOM**, иначе PowerShell 5 ломает пути.

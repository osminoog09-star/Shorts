На скрине показано `Colibri` с ~46.8k звёзд и Apache 2.0; это runtime для локального запуска больших MoE-моделей, **не** автоматическая генерация навыков в Claude Code. Подпись Instagram смешивает его с соседним AutoHarness.
Для M1lash пока НЕ ставить большие веса, не скачивать модели, не менять LLM backend или чужие API. Сохранён только подтверждённый указатель на код и описание. Исполнение требует отдельного согласования инфраструктуры и ресурсов.

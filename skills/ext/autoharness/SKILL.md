# AutoHarness — справочник M1lash, не работающий автоплагин

Проверенный upstream: https://github.com/tigerless-labs/autoharness (commit `ca4247b385d42a0d8dff25856301d2d2ef178c45`). Его собственные файлы лежат в `vendor/` **без** регистрации в `.claude-plugin`, `.mcp.json`, `.claude/settings.json` или `hooks/` корня. **Авто-перезапись навыков не запущена.**

Что полезно: Capture → Reflect → Promote → Lifecycle → Ledger. M1lash уже имеет `reports/learning/journal.json`, `tools/studio_learning.py` и утверждённое правило самопроверки — новая система не должна создавать второй реестр, перезаписывать `AGENTS.md`, удалять чужие навыки или писать в глобальные каталоги. Переносить идеи только после отдельного технического проектирования и локального теста с репетицией на временной папке.

Установленный исходник — **код для анализа**, не установленный в Claude Code плагин. Для полноценной установки требуется явное включение AutoHarness с пониманием, что его hooks захватывают содержимое сессии и создают/правят skills. Репозиторий M1lash остаётся под контролем владельца: каждое изменение GitHub коммитить, вести чекпоинт, QA, не собирать/не публиковать секреты/голос/кино.

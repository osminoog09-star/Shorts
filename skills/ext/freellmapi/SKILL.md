# FreeLLMAPI в M1lash (решение Дениса 05.11.2026: «надо нам»)
Источник: tashfeenahmed/freellmapi, MIT, коммит `fb07845faf7cf986ea9f3692e055076035dd8739`. Лицензия: `skills/ext/_licenses/tashfeenahmed_freellmapi.LICENSE`.
- Это сервер (Docker), ставится **на ПК Дениса**: `docker compose up -d` по docs/en/install/01-install.md, дашборд http://localhost:3001, ключи провайдеров добавляет сам Денис на странице Keys. Ключи никогда не в Git, не в чат, не в логи.
- В облаке/Actions не поднимаем (нет постоянного хоста; VPS платный — AGENTS §2).
- Наружу — один токен `freellmapi-…`; использовать как `OPENAI_BASE_URL=http://localhost:3001/v1`.
- Соблюдать условия каждого провайдера: один свой аккаунт на провайдера, без мультиаккаунтов.

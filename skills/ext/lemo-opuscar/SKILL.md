# Lemo-Opuscar · M1lash

**Установлена библиотека стилевых инструкций** из оригинала Lemomo, исходный commit `bebbbe1aa92a3cb4bb6f83500e61b23a17d1aa00` от 31.10.2026: `styles/README.md`, 66 `styles/<slug>/STYLE.md`, `DIRECTOR.md`, `TECHNIQUE.md`, `MY-STYLES.md`, `core/README.md`, `UPSTREAM_AGENTS.md`, `UPSTREAM_SKILL.md`, `scripts/setup.sh` и `LICENSE`. Источники: https://github.com/lemomo-ai/lemo-opuscar . Это адаптированный агентский skill для обоих агентов, не глобальная установка в ChatGPT/Claude и не готовый к работе рендер на каждом компьютере.

## Приоритет

1. Перед роликами: `tasks/NOW.md` (GPT/Codex), **корневой `AGENTS.md`**, `skills/m1lash-studio/SKILL.md`, затем текущий формат (`skills/film-mult/SKILL.md` и др.). При любом расхождении правила **корневого AGENTS.md выше** документов библиотеки `UPSTREAM_AGENTS.md`/`DIRECTOR.md`.
2. **Библиотека Opuscar не меняет утверждённые форматы, S10-D25 и выбранную владельцем глубину**; предлагает материалы и приёмы. Новый формат и масштабная переделка требуют решения владельца. `M1lash Мульт EP01` и `3D Coffee` продолжают PAUSED_BY_OWNER. Никакого автоматического публикационного доступа.
3. Основной голос = **личный Денис**, Qwen3-TTS по AGENTS §3, только approved концовка; не запускать upstream Kokoro/edge-tts по умолчанию. Музыку/SFX не подменять заготовками: проверять лицензию, фактический слуховой и художественный результат. Ничего не покупать и не использовать тарифицируемые API.
4. Работу по кодовой анимации вести в HyperFrames либо HTML+Canvas/Three.js+Playwright, без рисования сцен PIL. На серьёзном проекте: storyboard 4–6 кадров разных сцен → ART QA → настоящий motion pilot → финальный MP4 с `check.py` и `look.py`; `TECH_PASS` ≠ `ART_GO`.

## Как применять прямо сейчас, без загрузок

- Читать `styles/README.md`; выбрать технически полезные **2–3 референса** для конкретного уже согласованного проекта. Стиль **не копировать дословно**: взять отдельную приёмную механику (например, рисованный свет, print shader, накладные уровни параллакса, camera move) и адаптировать под M1lash.
- Открыть соответствующий `styles/<slug>/STYLE.md`, `DIRECTOR.md`, `TECHNIQUE.md`, создать свой `TREATMENT.md` и world/character bible. Не использовать исходные сюжеты демофильмов или картинки авторов как материалы.
- Правила конкретного стиля — технический справочник, а не отдельное разрешение расширить бюджет или обойти QA/голос.

## Runtime (отдельно от установленных инструкций)

Исходный официальный `scripts/setup.sh` включён **как есть для будущего осознанного запуска**: он клонирует/обновляет библиотеку в `~/lemo-opuscar` или `LEMO_OPUSCAR_HOME`; `deps` ставит npm/Chromium/Python (~350 МБ). Для реальной сборки требуются Node 20+, ffmpeg 7+, Python 3.11+ и зависимости стиля. Только когда требуется реальный рендер, в отдельной среде проверить скрипт и сделать preflight; не исполнять его из чужой папки и не разрешать destructive reset пользовательского репо. Обновление `main` вверх по течению может менять код: перед использованием сверить SHA и изменения.

```bash
# На разрешённой Linux/WSL-машине после проверки и наличия сети:
LEMO_OPUSCAR_HOME="$HOME/lemo-opuscar" sh skills/ext/lemo-opuscar/scripts/setup.sh
# И только если действительно нужен движок и разрешены большие загрузки:
LEMO_OPUSCAR_HOME="$HOME/lemo-opuscar" sh skills/ext/lemo-opuscar/scripts/setup.sh deps
```

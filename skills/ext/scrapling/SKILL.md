# Scrapling (M1lash адаптация)

Оригинальный официальный навык: `official/SKILL.md`, исходник https://github.com/D4Vinci/Scrapling/tree/3a4bb5b0a008233c85269a0a38a6d08edd4ce329/agent-skill/Scrapling-Skill . Содержимое оригинала скопировано только для изучения API. **Его рекомендации по обходу защит и автоматизации CAPTCHA не выполнять**. Соблюдать robots.txt, авторизацию, ToS, лимиты, не обходить DRM/CAPTCHA/anti-bot, не отправлять приватные данные. Перед любой реальной веб-загрузкой сверять `AGENTS.md` и наличие разрешения.

Реальное выполнение требует отдельного Python окружения и зависимостей `pip install "scrapling[fetchers]"`. В этой интеграции runtime/браузеры не установлены, никакая автозагрузка не запускается. Для исследования YouTube в M1lash использовать сначала `skills/ext/watch` и разрешённые официальные источники.

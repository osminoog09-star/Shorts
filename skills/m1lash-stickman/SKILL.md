## Бэкенд A — код (по умолчанию, 0 ₽)

Движок `skills/ext/anim-stick-figure` (rig `drawStick`, `kf()`-ключи, вспышки, whip-переходы, синтез SFX/музыки). На ПК без `setup.sh`:

```bash
cp -r skills/m1lash-stickman/demo_last_sock "C:/M1lash/Работа/<ролик>"     # шаблон с кириллицей (Unbounded) и Windows-рендером
cd "C:/M1lash/Работа/<ролик>"
python -m venv .venv && .venv/Scripts/python -m pip install numpy scipy soundfile   # только в папке ролика
node render.js stills 0.5,3.0,6.0            # стоп-кадры → stills/, смотреть глазами до полного рендера
.venv/Scripts/python -I audio.py             # audio/mix.wav
# полный рендер: node render.js segments 0,4 / 1,5 / … параллельно → seg/shot_XX.mp4 → concat → mux (как в make.sh движка)
python scripts/pc/local_jobs.py finish --body <body.mp4> --out "C:/M1lash/Готово/<имя>.mp4" --vertical   # из C:\M1lash\Shorts
```

- `render.js` берёт `playwright-core` из `longform/smart-strike/node_modules` и Chromium `ms-playwright/chromium_headless_shell-1248`. `require('playwright')` движка на ПК не работает, отсюда эта правка.
- Сцена в `web/shots.js`: `SHOTS.push({start, end, tr:'whip'|'cut', draw(ctx, lt, t)})`. Реквизит в `web/room.js` (комната, диван, робот-пылесос, носок, док, будильник, пузырь реплики, табло счёта). Для нового мира — новый `*.js`, подключить в `index.html`.
- Текст на экране — только `Unb` (Unbounded 800, кириллица). Шрифт движка Poppins кириллицы не имеет.
- Безопасная зона 9:16: x 100–980, y 220–1500. Табло и пузыри — сверху, лица не под ними.
- 8 сцен × 1 с рендерятся за ~1 мин на ПК (4 воркера). Проверять: рендер и запись по очереди (§2).

## Чек-лист раскадровки (до анимации)

- Герой одинаковый во всех сценах: голова, одежда, цвет, аксессуар.
- Одно направление движения по ролику (у нас — слева направо, к цели).
- В 0–1 с уже идёт действие: результат раньше объяснения.
- У каждой сцены своя роль и минимум 3 смены действия в секундах (таймлайн, как в промптах анимации у референса).
- Ясная цель кадра (носок, дверь EXIT, таймер) и развязка/поворот в последних 5 с.
- Пузыри реплик ≤ 2 слов, без воды. Без голоса держит ролик звук: SFX на каждом действии, музыка тише SFX.

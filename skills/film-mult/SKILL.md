# Фильм-мульт — S10-D25 (утверждено Денисом 04.11.2026)

**Триггер:** запрос «фильм-мульт», «нарисованный фильм», «анимационный фильм», «настоящее кино, но нарисованное», оригинальные истории с масштабными рисованными локациями. Это **производственный навык**, а не готовый фильм, автоматический генератор или отмена owner approval.

## Приоритет и границы

1. Первым делом читать `tasks/NOW.md` (GPT/Codex), `AGENTS.md`, `skills/m1lash-studio/SKILL.md`, `skills/m1lash-studio/references/visuals-by-code.md`, этот навык и уроки. AGENTS.md выше всех скилов; свежие решения владельца выше устаревших фраз ниже.
2. **Формат:** только **оригинальные истории** (не пересказы существующих фильмов/франшиз, не чужие персонажи, не ремейк референса). Создавать новый мир, персонажей, визуальные объекты, сюжет и монтаж; допустим анализ техники чужого ролика с отдельно проверенным источником.
3. **Стиль:** S10-D25. Рисованная кинематографическая постановка: художественно цельные иллюстрированные персонажи, детализированные локации, фактуры/свет/атмосферная перспектива; 2.5D — независимые слои и честный параллакс, а не переименованный плоский кадр. Не выдавать 2.5D за полномасштабное 3D.
4. **Не путать рубрики:** это отдельная форма, **не** «МультНовости» S3-D25, **не** «M1lash Мульт EP01» S9-D3, **не** киноразбор с отрывками. Пауза на `shorts/m1lash_mult_ep01` и отдельный 3D Coffee pilot продолжает действовать; утверждение навыка их **не возобновляет**.
5. Новую тему/проект, кастинг/права/траты решает владелец по AGENTS §2; этот уже утверждённый стиль не надо переутверждать в рамках Film-Mult. Ни роликов, ни YouTube upload, ни расписания без соответствующей команды. Нулевой автоматический бюджет.
6. Голос автора, главного героя, рассказчика и финала — **только личный Денис Qwen3-TTS** по актуальному AGENTS §3; женский второй голос выборочно с разрешённым происхождением, никакого старого «Дима». Голосовые исходники и готовые приватные медиа не коммитить в публичный Git.

## Визуальная ДНК S10-D25 (обязательная для art direction)

- **Рисованный кинематографический кадр:** цвет/свет как в иллюстрированном художественном фильме, не мультяшные «шарики/палочки», не случайные AI-картинки. Контур может быть выборочным; материалы распознаются по фактуре; общий цветовой сценарий меняется по драматургии.
- **Масштаб мира:** `WORLD_BIBLE.md` (карта связей локаций, архитектурный стиль, набор крупных/малых объектов, освещение, погода/атмосфера, ориентиры). Для истории с заводом/городом/флотом — показать широкую общую сцену, рабочие зоны, функциональные машины, движущиеся детали, массовку/транспорт и детали, а не один интерьер. Число локаций зависит от сценария, но нельзя подменять обещанный масштаб одинаковым задником.
- **Персонажи:** `CHARACTERS.md` и model sheet с лицом/силуэтом, ростом, палитрой, одеждой; 3 разных ракурса, 6 эмоций, 4 действующие позы. Одно лицо и костюм сохраняются между планами, персонаж узнаваем на общем/среднем/крупном.
- **Глубина:** минимум ближний / средний / дальний план, отделяемые слои, правильная окклюзия и тени, камера со смыслом (выезд из пространства, панорама раскрытия масштаба, смена крупности по реакции). Простой zoom на одной картинке ≠ полноценная новая сцена.
- **Актёрское действие:** событие → подготовка → физический контакт/изменение мира → реакция → завершение. У тела/лица/взгляда/рук свои причинные движения; смена поз и выражений, перспектива, физика предметов. Избегать синусоидального «вечного покачивания».
- **Монтаж и ритм:** первые 2 секунды — визуальное событие, сразу конфликт/цель. Широкий → средний → крупный → реакция, смена плана или смыслового действия обычно каждые 5–8 с по AGENTS; монтаж не скрывает отсутствие сцен. Удерживать эмоциональный контраст: напряжение/разрядка/новое препятствие.
- **Звук как часть мира:** слой голоса, атмосфера пространства, синхронный SFX конкретных действий, только легальная музыка. Звуки механики/взрывов/шагов соответствуют точному видимому событию, иначе убрать.
- **Текст:** вспомогательный; не основной экран. Никаких долгих карточек, мелких подписей, «?», схем из палочек, бесконечных клонированных фонов или заглушек.

## Производственный конвейер

**Этап A — история и библия мира.** В `longform/film_mult_<id>/` создать `BRIEF.md`, `WORLD_BIBLE.md`, `CHARACTERS.md`, `SCRIPT.md`, `PRODUCTION.md`. Готовая история = герой с конкретной целью, сопротивление среды/антагониста, эскалация, середина с изменением ситуации, кризис, кульминация, причинная развязка. Каждая локация и объект должны что-то делать для истории. Для длинных новых выпусков минимум 21:00 по AGENTS (целевой хронометраж 21–23 мин, **не растягивать** сценами и музыкой).
 
**Этап B — режиссёрский шотлист и аниматик.** `shotlist.csv`: `shot_id,start,end,location,characters,hero_prop,story_beat,action,pose_or_expression,camera,size,near_mid_far,lighting,dialogue_speaker,audio_cue,asset_ids,qa_times`. Не менее одного осмысленного действия/визуального изменения на план. Сначала рассчитать длительность по реальным голосовым репликам, затем собирать аниматик; не назначать 21 минуту при 5 мин текста.

**Этап C — asset/model gates.** Собственный versioned набор художественных героев, декораций, переднего/среднего/дальнего фона, реквизита, света, VFX. `assets_manifest.json` хранит пути, версии, лицензию, совместимость с рендером, контрольные кадры. Процедурно построенные детали допустимы, если выглядят как объекты мира, а не кубы. Генерация ассета **не равна** разрешению на создание иллюстрации вместо CGI. Проверить model sheet и композицию.

**Этап D — 4–6 реальных стопов ДО видео.** Кадры из **разных локаций/состояний** (общий масштаб, герой крупно, действие с реквизитом, эмоциональный контраст, сложное окружение, кульминационный потенциал), `1920×1080`. Запуск из HyperFrames (локально), HTML+SVG/Canvas/WebGL+Three.js+Playwright или Remotion из существующей системы. Не рисовать сцены PIL; PIL можно использовать для служебной сборки контакт-листа. Глазной ART QA на каждом кадре, с явным NO-GO при плохой анатомии, наложениях, плохой перспективе, пустых окружениях.

**Этап E — настоящий motion pilot.** Сначала 8–10 с **сложнейшего** действия, затем 15–30 с связного фрагмента с актёрской реакцией и настоящим голосом/звукорежиссурой, если voice preflight успешен. На паузу при отказе runtime. Декодировать MP4, смотреть кадры каждые 0.5 с и слушать; 6 красивых JPEG никогда не дают ART PASS. Показывать реальные «до → контакт → последствия», проверять предметы/кисти/лица/безопасные зоны и монтажные стыки.

**Этап F — сборка полного выпуска.** Детерминированный покадровый таймлайн, 30 fps, H.264 yuv420p, AAC 48 kHz, 1920×1080. Рендерить сценами/актами, не монолитно, сохранять id/таймкоды, логировать render failures. Голос/музыка/SFX сводятся после целевых проб; approved Denis v7 horizontal outro присоединять **только** штатным `tools/assemble_with_outro.py --horizontal` (проверить реальные текущие флаги/схему). Правообладателей не копировать, содержимое protected assets и voice не пушить.

**Этап G — жёсткий QA (TECH и ART отдельно).** `python3 scripts/qa/longform_duration_gate.py FILM.mp4`; официальный `skills/ext/ffmpeg-skill/scripts/check.py FILM.mp4 --platform youtube` + `look.py FILM.mp4 --tiles 3x2` на **финальном** MP4; `ffmpeg -xerror` полный A/V decode; контакт каждого уникального плана, 1 кадр/с для длинного, ключевые взаимодействия по 0.5с, слуховой просмотр. Отдельно проверить цельность сюжета, живость персонажей, смену ракурсов, пропорции локаций, синхронизацию губ (только при достоверных таймингах), громкость/финал. Статус минимум `TECH_PASS/FAIL` и `ART_GO/NO_GO`. При NO-GO запрещены `READY`, приватная заливка и публикация. При успешном QA — только private review по AGENTS §6 и личный «ок» владельца на дату.

## Обязательная работа с референсами (не фантазировать)

Перед выбором художественных приёмов использовать `skills/m1lash-reference-analysis/SKILL.md`, `skills/ext/watch/SKILL.md` (если применимо), `references/REFERENCE_AUDIT.md`.
- Ссылка/обложка/SEO/описание ИИ без проверенных кадров дают максимум `AUTO_SUMMARY_UNVERIFIED`. Только прямой доступ к видео, `ffprobe`/выборка физически декодированных кадров, визуальная проверка переходов и реальный слуховой анализ позволяют утверждать стиль, длительности планов, тип движения.
- Если доступ к YouTube блокируется, **не обходить** DRM, cookies, CAPTCHA, антибот и не выдавать предположение за факт; записать `SOURCE_BLOCKED` / `UNVERIFIED`, запросить разрешённый исходник **только если без него нельзя продолжать**. Разбирать доступные источники независимо.
- Из чужого переносим композиционные принципы (сначала пространство → действие → лицо → последствия), не чужие кадры, героев, музыку, историю и точный монтаж.
- У каждого референсного наблюдения поля: `timecode,description,source_method,confidence,verified_pixels,verified_audio`. Считать качество **пока не измеренным**, если не было визуального теста.

## Автопроверка перед стартом

- `python tools/studio_learning.py preflight` (при доступном runtime).
- Найти `tasks/NOW.md` и при работе >15 мин вести шаги с push после каждого.
- Сверить доступные `hyperframes-registry`/действующий `motion-render.yml`, `skills/vizavi-motion/references/style-library.md`, `skills/m1lash-studio/references/visuals-by-code.md`.
- Перед созданием новых scripts/workflows/ассетов искать готовые блоки в репо, не плодить дубль.
- Измерять фактические тесты, а не объявлять готовность по плану.

# Улучшения качества (решение Дениса 24.10) — обязательно для Claude и Codex

## Графика
1. **Реальные PBR-текстуры, CC0:** Poly Haven (polyhaven.com) и ambientCG (ambientcg.com) — дерево, бронза/патина,
   мрамор, камень, ткань. Карты color/roughness/normal (1–2K). Стиль остаётся стилизованным, но материал читается.
   Скачивать в workflow GitHub Actions (там есть интернет), класть в `media/textures/<имя>/` с файлом `LICENSE.txt` (CC0, источник).
2. **HDRI-освещение** с Poly Haven (студийные/интерьерные панорамы, CC0) вместо одного RoomEnvironment — для отражений металла и стекла.
3. **Мягкое затенение щелей (GTAO/SSAO)** в постобработке — объём и «вес» деталей.
4. **Готовые модели для фона/реквизита:** Poly Haven (CC0), Sketchfab только с лицензией CC0/CC-BY (CC-BY — автор в описании).
   Главный объект — свой, сцену наполняем готовым. Формат GLB/glTF.
5. **Мелкие детали обязательно:** фаски, болты/заклёпки, стыки, гравировка и таблички, царапины, мелкий реквизит.
6. **Следующий шаг (по решению Дениса):** рендер в Blender (бесплатно, headless в GitHub Actions) — студийный свет, стекло, тени.

## Подача
7. **Крупные планы (макро)** с сильной глубиной резкости: шестерня, капли, гравировка — минимум 1 на сцену.
8. **Передний план:** камера проходит мимо колонн/предметов — параллакс и глубина.
9. **Смена картинки каждые 5–8 с:** новый ракурс, деталь крупно, перемещение камеры, вспышка.
10. **Не слайд:** без постоянных шапок/рамок/счётчиков; объект крупно; короткие подписи-тезисы, а не длинные субтитры плашкой.

## Удержание
11. **Хук в первые 5 с:** самый сильный факт/кадр ролика, без вступлений.
12. **Повторный крючок каждые 1,5–2 мин:** «а дальше выяснилось кое-что странное…».
13. **Финал:** просьба подписаться + спасибо всем, кто досмотрел и поставил лайк, + вопрос в комментарии.

## Звук
14. **Живые шумы** с Freesound — только CC0 (CC-BY — с атрибуцией в описании): дерево, бронза, вода, ветер, шаги.
    Хранить в `media/sfx/` с `LICENSE.txt`. Музыка — по `music-and-license.md`.

## Канал
15. **2–3 варианта обложки** на каждое длинное (`thumb_a.jpg`, `thumb_b.jpg`, `thumb_c.jpg` в папке проекта) —
    Денис ставит A/B-тест в YouTube Studio («Тест и сравнение»).
16. **Разбор удержания** через 2–3 дня после выхода длинного (YouTube Studio / vidIQ): где уходят зрители — записать
    вывод в `STRATEGY.md` и исправить в следующем ролике.

## Анимированная карта — обязательный урок Samsung V3, 28.10.2026

Для любой карты стран, островов, брендов, санкций и маршрутов дополнительно ОБЯЗАТЕЛЕН [географический release gate](geography-map-video-qa.md). **Счётчик 159/159 не означает, что 159 стран правильно нарисованы.** Каждая страна должна иметь полигон/inset, верную географическую точку и реальный аудио-cue. Персонажи не должны плавать над морем, а указатели — вести в предыдущую страну. Формульное равномерное переключение стран и субтитры строго по N словам запрещены. При любом P0 FAIL ролик не готов; повторно проверять источник, геометрию, кадр, звук и фактические статусы до экспорта.

Предрендерный инструмент: [scripts/qa/map_release_gate.py](../../../scripts/qa/map_release_gate.py) и журнал ошибок [Samsung Full V3](../../../reports/quality/samsung-v3-screenshot-defects-20261028.md) в рабочей ветке Samsung; ошибки выявлены на 17 пользовательских кадрах. Инструмент нужен для автоматической части; художественная и аудио-проверка остаются обязательными.

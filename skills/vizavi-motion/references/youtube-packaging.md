# Упаковка для YouTube (после экспорта, обязательно)

- **Название** ≤ 70 символов: интрига + предмет. Без флагов стран, без кликбейта, противоречащего фактам.
- **Описание:** 2–3 предложения сути → главы (00:00 …) → источники → атрибуция музыки → вопрос в комментарии → 3–5 хештегов.
- **Теги:** 10–15, от точного («антикитерский механизм») к широкому («история науки»).
- **Обложка:** 1280×720, герой крупно, 2–3 слова огромным шрифтом, читается на телефоне.
- **Категория:** EDUCATION для лонгридов, не для детей.
- **Раскрытие ИИ:** отмечай «синтетический контент», только если ролик показывает реалистичных людей/события, которых не было;
  стилизованная 3D-анимация и синтезированный голос диктора к этому не относятся.
- Файл с метаданными — `longform/<проект>/PUBLISH.md`.
- Нарезки Shorts из лонгрида: 3–4 штуки, после выхода основного видео, по правилам `AGENTS.md`.

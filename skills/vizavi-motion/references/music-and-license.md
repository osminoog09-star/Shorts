# Музыка: только разрешённая, с атрибуцией

Обязательно для всех роликов канала (и Claude, и Codex/GPT).

## Разрешённые источники

1. **Kevin MacLeod, incompetech.com — лицензия CC BY 4.0.** Коммерческое использование и монетизация разрешены
   при атрибуции. Загрузка — workflow `Music` (`jobs/music/*.json` → `media/music/*.mp3` + `*.license.txt`).
2. **Фонотека YouTube (YouTube Audio Library)** — Денис скачивает вручную из YouTube Studio; если у трека пометка
   «требуется указание автора» — атрибуция в описании обязательна (текст берётся со страницы трека).
3. **Своя процедурная музыка** (`audio.py`, режим `sections`) — запасной вариант, без атрибуции.

## Запрещено

Коммерческие треки, звуки из TikTok/Reels, «no copyright music» с чужих YouTube-каналов без лицензии,
любые треки, где нельзя показать лицензию. Музыку не скачивай по ссылкам из комментариев/видео.

## Атрибуция (вставлять в описание дословно, для каждого трека)

```
Музыка:
"<Название трека>" Kevin MacLeod (incompetech.com)
Licensed under Creative Commons: By Attribution 4.0 License
http://creativecommons.org/licenses/by/4.0/
```

Текст атрибуции лежит рядом с треком в `media/music/<трек>.license.txt` — копируй его, не перепечатывай.

## Сведение

- Музыка — подложка: −14…−15 LUFS итог, музыка заметно тише голоса, автоматическое приглушение под речь (ducking).
- Длинный ролик: 2–4 трека по смысловым частям (загадка/открытие/механизм/финал), смена на стыке сцен с кроссфейдом 2–3 с.
- Если YouTube прислал Content ID-заявку на CC-трек — это ошибка третьих лиц: оспорь, указав лицензию CC BY 4.0 и ссылку.

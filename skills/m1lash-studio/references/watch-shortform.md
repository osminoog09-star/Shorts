YouTube иногда блокирует облако; тогда без обходов запрашивается законно доступный MP4 либо использующаяся разрешённая среда; до этого `SOURCE_BLOCKED`. ## Запуск для доступного MP4/публичной ссылки

```bash
python3 skills/ext/watch/scripts/setup.py --json
python3 skills/ext/watch/scripts/watch.py 'VIDEO_URL_OR_LOCAL.mp4' \
  --intent 'Разобрать первые 2/10 секунд, ритм, повороты, визуальные сцены, монтажные акценты, звук и титры ради оригинального M1lash Shorts' \
  --no-whisper --out-dir '/tmp/watch-m1lash'
```

Выходы: кадры (на реальных склейках), плотный хук 0–10с, pacing, `report.md`, если доступна — native captions; для полного анализа озвучки использовать отдельно легально разрешённый офлайн ASR и прослушивание. Формат доказательств, JSON уроков и список четырёх пользовательских референсов — по playbook.

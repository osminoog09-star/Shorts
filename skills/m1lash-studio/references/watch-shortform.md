# M1lash Studio — /watch для улучшения Shorts

Решение владельца 03.11.2026: выбран **вариант 2 — /watch**. Запускать уже установленный `skills/ext/watch/scripts/watch.py` как Python-процесс; скрипт совместим с GPT/Codex и Claude при наличии shell, Python, ffmpeg/ffprobe, yt-dlp и исходника. Читай полную инструкцию: `skills/m1lash-reference-analysis/references/watch-shorts-playbook.md`.

**Контракт фактов.** Ссылка — не доказательство, что ролик посмотрели. Точная визуальная/звуковая разметка возможна только по физически доступному видео, выведенным кадрам и транскрипту. YouTube иногда блокирует облако; тогда без обходов запрашивается законно доступный MP4 либо использующаяся разрешённая среда; до этого `SOURCE_BLOCKED`. В vidIQ закончились кредиты анализа; повторный расход не инициировать. Не использовать незнакомые скилы из референса без подтверждения названия, лицензии и кода.

## Запуск для доступного MP4/публичной ссылки

```bash
python3 skills/ext/watch/scripts/setup.py --json
python3 skills/ext/watch/scripts/watch.py 'VIDEO_URL_OR_LOCAL.mp4' \
  --intent 'Разобрать первые 2/10 секунд, ритм, повороты, визуальные сцены, монтажные акценты, звук и титры ради оригинального M1lash Shorts' \
  --no-whisper --out-dir '/tmp/watch-m1lash'
```

Выходы: кадры (на реальных склейках), плотный хук 0–10с, pacing, `report.md`, если доступна — native captions; для полного анализа озвучки использовать отдельно легально разрешённый офлайн ASR и прослушивание. Формат доказательств, JSON уроков и список четырёх пользовательских референсов — по playbook.

## Универсальный авторский промпт (не копия чужого ролика)

> Ты режиссёр Shorts канала M1lash. Сначала прочитай AGENTS.md, Studio SKILL и отчёт /watch исходного референса. Перенеси **приёмы, но не контент**: сильный визуальный хук в 0–2 с, чёткое действие вместо заглушек, 4–6 уникальных сцен, осмысленные эмоциональные реакции и ритмичные монтажные акценты, а также развязку перед фирменным outro. Напиши новый оригинальный сценарий по другой истории/образам. Выбранный Денисом стиль S#-D# строго по style-library, действие кодом в HyperFrames/HTML+Three.js+Playwright, а не PIL. Текст не закрывает лицо и UI. Новые озвучки — **только голос Дениса** на Qwen3, без подмены; концовка — approved Denis v3 music80 6.6 с. Протокол: факты из конкретных timestamp референса → карта нового сюжета → 4–6 стоп-кадров (визуальная оценка) → 5–10 с пилот → полный рендер и физические `check.py`/`look.py`/full decode/аудио QA. Не публиковать и не назначать даты до решения владельца. Опиши 3 улучшения относительно референса и метрики их проверки.

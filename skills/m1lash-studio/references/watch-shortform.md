YouTube иногда блокирует облако; тогда без обходов запрашивается законно доступный MP4 либо использующаяся разрешённая среда; до этого `SOURCE_BLOCKED`. ## Запуск для доступного MP4/публичной ссылки

```bash
python3 skills/ext/watch/scripts/setup.py --json
python3 skills/ext/watch/scripts/watch.py 'VIDEO_URL_OR_LOCAL.mp4' \
  --intent 'Разобрать первые 2/10 секунд, ритм, повороты, визуальные сцены, монтажные акценты, звук и титры ради оригинального M1lash Shorts' \
  --no-whisper --out-dir '/tmp/watch-m1lash'
```

Выходы: кадры (на реальных склейках), плотный хук 0–10с, pacing, `report.md`, если доступна — native captions; для полного анализа озвучки использовать отдельно легально разрешённый офлайн ASR и прослушивание. Формат доказательств, JSON уроков и список четырёх пользовательских референсов — по playbook.

## Успешный доступ к YouTube в GPT через Higgsfield (04.11)

Когда облачный `yt-dlp` не может скачать видео, сначала проверить доступный подключённый `Higgsfield.video_analysis_create({youtube_url})`, затем `Higgsfield.video_analysis_status({video_analyze_id})`; работает на Shorts по прямой публичной ссылке. Для четырёх ссылок из текущего исследования статус `completed`, вернулись разметка времени, описание кадров и речь. Это **анализ видеомодели, не человеческий просмотр JPG/исходного MP4**. Без самостоятельного frame/audio decode не заявлять `PIXELS_AND_AUDIO_VERIFIED`. Не включать платный тариф и не обходить антибота. Разбор со всеми наблюдениями: `reports/research/references/2026-11-04_four_shorts_video_analysis.md`.

## Универсальный авторский промпт (не копия чужого ролика)

Перенеси **приёмы, но не контент**: сильный визуальный хук в 0–2 с, чёткое действие вместо заглушек, 4–6 уникальных сцен, осмысленные эмоциональные реакции и ритмичные монтажные акценты, а также развязку перед фирменным outro. Напиши новый оригинальный сценарий по другой истории/образам. Выбранный Денисом стиль S#-D# строго по style-library, действие кодом в HyperFrames/HTML+Three.js+Playwright, а не PIL. Текст не закрывает лицо и UI. Новые озвучки — **только голос Дениса** на Qwen3, без подмены; концовка — approved Denis v3 music80 6.6 с.

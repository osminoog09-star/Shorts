# Новости M1lash · 28 октября 2026

Авторский новостной разбор Amazon, Cloudflare и Opera, отдельный вертикальный Shorts. Исходники — native huashu-motion 0.3.1 (alchaincyf/huashu-motion, commit 52467f99c602b76ba86d511d37acdfe93fa1e16e), HTML/GSAP/Canvas и OM.clock. Старый render.py — только отклонённый визуальный черновик.

## Что воспроизводит выпуск

1. `audio_batches.py` — точный Edge ru-RU-DmitryNeural +0%, JSON WordBoundary и манифест голоса каждого сегмента. Уже принятые записи не синтезировать заново.
2. `edit_timeline.py` — редакционный монтаж, 31 глава, измеренная речь без ускорения. Удалены повторяющиеся примеры 5/16/30; необязательные блоки 31–34 исключены при сборке озвучки.
3. `host.tsx` — одобренный Narrator2 за столом; `native_prepare.py` — PNG и настоящие Rhubarb phonetic cues.
4. `build_native.py` — редактируемая отдельная HTML-композиция каждой главы и отдельная композиция 1080×1920. Иллюстративная геометрия помечена на экране.
5. `render_native_batch.py` — om check, om sound, om render (30 fps), om qa, trim до измеренной речи с коротким окончанием, полный decode каждого MP4 и обзорные кадры.
6. `join_native.py` — склейка, нормализация звука, полный decode, размеры, A/V drift <=0.25 s, основной фильм >=21:00; главы описания рассчитаны по готовым частям.

CI: `.github/workflows/news-native-final.yml`. Принятые озвучки: run 40749534199. Базовые native masters: run 40751990901. Выборочная финальная правка первой сцены, длинных титров и Shorts: run 40752722147. Старые частичные артефакты и пилоты не выдавать за финальный выпуск.

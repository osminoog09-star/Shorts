# «Притворись ботом: проверка на человека»

Горизонтальный 1080p выпуск M1lash по собственному Shorts keMWV5guOLw. Драматический вопрос: сможет ли офис с идеальными цифрами сделать работу, результат которой проверит живой человек? В начале чек требует списать сотрудников; в финале чек просит честную обратную связь. Окружение меняется от офиса к проходной, двору и мастерской, затем к вечернему входу и кофемашине.

- Новые персонажи: Тамара, мастер поддержки Коля и проверяющий на колёсах. Лида и рассказчик развивают установленные роли серии.
- Рисованная 2.5D анимация. Пять типов планов, отдельные профили персонажей и многоразовые, но по-разному поставленные локации. Контакт брелока, сигнал и открытие двери анимированы отдельной сценой.
- Утверждённый Денис Qwen ICL, речь без ускорения. Синтетические звуки действий созданы локально, тело без фоновой музыки. Горизонтальная концовка v7 присоединяется штатной сборкой.
- Донорский файл только для анализа. Никакие его видеофрагменты и звуковые дорожки не подставлены в историю.

## Сборка на ПК

Выполнить из корня репозитория. Приватная работа и кэш: `C:/M1lash/Работа/bot_audit_20261112`. Canvas по умолчанию использует рабочую установку студии под `weather_bureau_runtime`; допускается `M1LASH_CANVAS_MODULE`. Без параллельного захвата экрана.

1. `python -X utf8 longform/bot_audit_20261112/voice_full.py`, `build_timeline.py`, `finish_audio.py`.
2. `node longform/bot_audit_20261112/film.cjs stills`, `pilot`, `opening`, `animatic`. Аниматик смиксовать с mix.wav и проверить командой `coverage.py`.
3. Только после визуального GO и проверки SHA аниматика выполнить `render_final.py`. Собрать body.mp4 с approved horizontal outro.
4. Проверить готовый MP4 по декодированию, длительности, loudness и реальным кадрам. Отдельный SRT генерируется из принятых голосовых реплик. Слуховая оценка отдельна от ASR.

Сценарий: `narration.md`. Постановки: `staging.json`. Разбор: `reports/research/references/keMWV5guOLw/reference_audit.md`. Исходные видео, голос и готовый MP4 хранятся локально.

## Ревизия V2

V2 хранит результаты в отдельном каталоге `BOT_AUDIT_WORK`. В него копируются принятые `timeline.json` и `mix.wav`. Команда `python -X utf8 longform/bot_audit_20261112/voice_envelope.py <narration_raw.wav> <BOT_AUDIT_WORK>` строит огибающую артикуляции с шагом 1/30 с. Это амплитудное открытие рта, без фонемных визем. Речь заново не синтезируется.

`film.cjs review` выводит шесть пробных окон. `film.cjs animatic` выводит полную визуальную пробу. После проверки кадров нужно записать SHA аниматика и решение в `animatic_review.json`, затем выполнить `render_final.py` с тем же `BOT_AUDIT_WORK`. Использовать `tools/assemble_with_outro.py --horizontal` и проверять итог по `check.py --platform youtube --content`, Watch, кадрам каждого плана и сравнительному анализу звука. V1 и V2 — отдельные MP4.

## Ревизия V3

V3 использует исходные тайминги и мастеринг V2. В рабочий каталог V3 копируются `timeline.json`, `mix.wav` и `voice_envelope.u8`. Режим `film.cjs review` выводит проходную, сверку карточек, помощников, журнал участников, тележку и снятие коробки. Общие изменения в отрисовке персонажей и фонов требуют заново отрендерить все восемь глав.

После сборки проверить точный финальный MP4 в Watch, сравнить аудиопоток с V2, проверить внешний SRT и записать оценки в `V3_AUDIT.md`. Финальные MP4 и рабочие материалы остаются на ПК.

## Ревизии V4 и V5

V4 добавляет предметные действия и читаемую информацию во всех восьми главах. Для микса V4/V5 выполнить `python -X utf8 longform/bot_audit_20261112/foley_v4.py <mix_V3.wav> <BOT_AUDIT_WORK/mix.wav>`.

Для V5 построить `mouth_poses.u8` командой `python -X utf8 longform/bot_audit_20261112/mouth_poses.py <базовый рабочий каталог> <BOT_AUDIT_WORK> <локальная модель faster-whisper-small>`. Базовый каталог содержит `narration_raw.wav` и локальный `full_audio_audit.json` с границами реплик. В каталоге V5 должны быть исходный таймлайн и `voice_envelope.u8`. Формы рта приближённые.

После исходного рендера выполнить `python -X utf8 longform/bot_audit_20261112/tighten_v5.py <BOT_AUDIT_WORK>`. Это создаёт `body_cut.mkv` и `timeline_final.json`. Собрать `body_cut.mkv` со штатной горизонтальной концовкой. `captions_v5.py <SRT V3> <SRT V5>` убирает вырезанные блоки и сдвигает таймкоды. Проверить MP4 и сверить смещение речи вокруг всех трёх стыков.

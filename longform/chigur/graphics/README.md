# Чигур — контроль графики REV18/REV19

Это **исторические исходники** проблемной графики, а не разрешённый способ делать новую анимацию. Кино-кадры и аудио в GitHub отсутствуют.

- `new_graphics_ranges.json` — 28 точных временных интервалов (276 с) и подписи из локального REV18 ZIP, применявшиеся при создании REV19.
- `legacy_rev18_pil.py` — восстановленный для аудита функциональный код старого PIL-подхода. Нельзя запускать его для новой пользовательской графики: противоречит `AGENTS.md` §10 и `skills/m1lash-studio/references/visuals-by-code.md`. В нём сохранены локальные пути старого окружения; это **не** готовая production-сборка.
- Рендер REV19 до 1080p без нового рисунка не меняет качество персонажей, света и постановки. Подробно: `reports/research/2026-11-01_CLAUDE_AUDIT_REV19_V21.md`.

**Новая версия:** предметные сцены в HyperFrames или HTML+Three.js+Playwright, ориентир `tools/outro/`. Сперва 4–6 разных стоп-кадров и 5–10 секунд тестового движения, только потом заменять все 28 окон. Не перемикшировать кино-аудио и не накрывать доказательные фрагменты.

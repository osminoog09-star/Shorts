# «Компьютер, которому 2000 лет» — раскадровка

Формат: 1920×1080, 30 fps (2 CPU без GPU — 60 fps удвоит рендер без выигрыша для комикс-стиля), H.264 + AAC, ~4 мин.
Стиль (бриф Дениса): комикс/стикеры — толстая чёрная обводка, плоские яркие цвета, белая вырубка у стикеров,
полутона, звуковые надписи; упругое движение (прыжки, squash/stretch, overshoot, линии действия);
стилизованные объёмные формы в 3D, перспектива, мягкий свет, осмысленная камера.

Техника: Three.js (toon-материалы) → пост-проход: обводка по разрывам глубины/нормалей, полутоновые точки в тенях,
бумажное зерно. Поверх — 2D-слой стикеров и звуковых надписей. Детерминированный `renderAt(t)`, кадры через headless Chromium → FFmpeg.

Палитра: море #1FB5C9, солнце #FFD23F, бронза #F08A24, патина #3FBF8F, красный #FF4A3D, бумага #FFF3D6, чернила #111.

Единая нить: **механизм — герой**. Он лежит комом → его просвечивают → он раскрывается → крутится → разворачивается в космос.
Каждая сцена «разбирает» его на шаг глубже; финал — он рядом с нашими компьютерами.

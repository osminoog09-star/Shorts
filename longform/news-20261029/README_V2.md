# M1lash News: редакционная переделка V2

Полный выпуск26:50. 2D-стиль прямо задан владельцем для этого выпуска; не переводить его автоматически в3D по старому общему шаблону. Кодовая2D-анимация,150 смысловых планов,8 тем, проверенные ранее голоса Димы и Светланы. Исправлены цветные вспышки, краткие попадания финала в паузы и циклическое переключение рисунков.

Главный файл `index.html` использует `full_data.js` (реальные тайминги озвучки и Rhubarb), `shot_plan.js` (план монтажа) и `film.js` (детерминированная анимация).

## Восстановление и рендер

В исходномZIP: папка `project` и соседняя `input/original_audio.m4a`. ВходнойAAC получен из предыдущегоMP4, сохранён без перекодирования и содержит утверждённые Диму/Светлану, собственную музыку и эффекты. Отдельные исходные голосовые файлы и provenance — в `audio_verified/` и манифесте. Никакой иной голос не нужен.

Из `project`: `npm ci`, затем `python3 tools/render_motion_all.py`. НужныNode24+, Python3, FFmpeg. Движокна @napi-rs/canvas; кадры1920×1080,30fps, Промежуточные H264 CRF16 ultrafast из сырых RGBA-кадров. Параллельно8 частей, затем единый H264 CRF20 fast и перенос исходногоAAC без перекодирования. В веб-превью таймлайнGSAP+OM, `renderAt(seconds)` идентичен нативному алгоритму.

Редактура: `shot_plan.json` — время, режим, титр и уточнение каждого плана. После ручной правки запустить `python3 tools/sync_plan.py`. Менять исходноеаудио и длину при правке текста без новогоTTS нельзя. `full_data.js` содержит липсинк и точные границы фактического звука.

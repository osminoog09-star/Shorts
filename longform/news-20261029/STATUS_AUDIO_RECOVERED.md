# 29.10.2026 — звук восстановлен

Монтажная звуковая версия: **1609.976 секунд (26:49.976)**, 69 сегментов. Основной рассказчик и CTA — ru-RU-DmitryNeural, второй голос — ru-RU-SvetlanaNeural. Скорость +0%, движок edge-tts 7.3.1. Нет замены на Piper, Liam или произвольный голос.

Путь восстановления: сравнен рабочий Serve-код из codex/serve-s4d25-voice-20261029, затем стандартный SentenceBoundary вместо WordBoundary, повторные запросы, отдельный кэш успешных файлов. Короткий тест не считался доказательством готовности всего текста. У сервиса были NoAudioReceived, таймауты и обрезанные аудиофайлы. Конкретную единственную корневую причину нестабильности не установили; не утверждать, что всё исправлено только сменой режима.

Проверено для каждого использованного сегмента: точный разрешённый voice ID, полный текст метаданных, совпадение с исходным текстом (кроме явно документированного монтажа), ffprobe, соответствие конца речевых metadata физической длительности, самостоятельный сохранённый файл. Файлы с обрывами отвергнуты. Ведущему сформированы Rhubarb phonetic-виземы по реальным MP3. Фон — собственная процедурная музыка и синтезированные эффекты; без неподтверждённого Laeko.

Сведение: loudnorm target -16 LUFS / -1.5 dBTP. Измеренный MP3: -16.23 LUFS, true peak -1.52 dBTP, LRA 3.10 LU. Файл содержит настоящую речь, не тишину или одну музыку. Версия начала 61.284 секунд передана отдельно.

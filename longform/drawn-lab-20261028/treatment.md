# M1lash · рисованная лаборатория · 28.10.2026

Поручение: один новый длинный фильм >=21:00, два самостоятельных научных Shorts и дополнительно киношортс-загадка. Владелец выбрал кодовую реализацию и предложил рисованный стиль; допускается самостоятельное художественное решение. Это исключение к старому 3D-default, а не изменение всех прошлых роликов.

Выбрана hand-drawn + mechanism: настоящая причинная анимация на большом листе, обводки, штриховка, ластик стирает неверное объяснение и открывает механизм. Не последовательность одинаковых карточек и не набор цветных кубов. Две краски канала — синий и розовый — остаются в акцентах; тёмный графит, светлая бумага, маленькие тёплые метки. Стилизация ведущего строится из того же Narrator2/HostCorner, не из персонажа автора huashu-motion. Лицо, волосы, наушники, стол и микрофон узнаваемы. Одна и та же ru-RU-DmitryNeural +0% во всех сегментах, настоящий Rhubarb.

Три рассмотренных направления: A рисованная лаборатория с ластиком (выбрано по просьбе владельца); B предметный 3D-разбор корпуса; C редакционный коллаж из документации. Для отдельных сцен storyboard.csv сравнивает причинное действие, схему и бытовую аналогию. Предметы выводятся из темы, а не из одного шаблона.

Ритм: hybrid, narration-led. Hook — уменьшающийся заряд при спящем экране, движение в первые 0.1 s. Энергия 8 -> 5 -> 7 (разбор химии) -> 4 (читать условия) -> 8 (одновременно экран/связь/нагрев) -> 5 (зарядка) -> 7 (собираем диагностику) -> 3 (финал). Акцент по словам, не механический одинаковый cut каждые 6 секунд. Общий объект-телефон связывает главы; внутри главы 4–7 смысловых подшотов, draw-on и стирание, крупный механизм, остановка для чтения, изменение результата. Музыкальные разделы по механизму/поиску/мифам/выводу; оригинальная процедурная музыка, карандашные/бумажные SFX, voice ducking.

Обязательные реальные кадры: hook, химия/внешняя цепь, плотная диагностика, финал с ведущим; native om still до полного рендера. Сначала hardest shot, затем пилот, затем полный экспорт. Финалы научных видео: полный утверждённый CTA Димой, без смены голоса.

Киношортс: реальные чёрно-белые кадры немого фильма из источника с пометкой public domain. Собственная русская авторская озвучка явно обозначена; не выдавать её за оригинальный дубляж. 9:16 full-bleed reframe по действию; источник низкого исторического разрешения не называть современным HD-мастером. Внутренний бриф содержит название/алиасы/права, публичные поля — нет. Название только последние произнесённые слова после CTA; не выводить его титром. Музыка из исходника полностью удаляется. Проверка validate_mystery.py и фактических кадров обязательна.

Экспорт: основной 1920×1080, 30fps, измеренная длительность >=1260 s без ускорения/замедления/пустого хвоста. Shorts отдельные 1080×1920 композиции. Полный decode каждого файла, fps/pixel format/audio/duration/A-V drift <=0.25 s, начало/стыки/конец, источники/лицензии, недопустимость спойлеров. Техническая приёмка не означает гарантированную эффективность или субъективную оценку 10/10. Автопубликация не запрошена.

Текущая версия — полная переделка по замечаниям Дениса 24.10.2026. Первая версия 9:41 отклонена; её посты в Metricool переведены в черновики.

- Большой ролик: **11:10,3**, 1920×1080, 30 fps; два самостоятельных вертикальных 3D-рендера 1080×1920 на 40 и 35,5 с.
- Единый голос ru-RU-DmitryNeural. Темп 1,20 вместо 1,3956: диктор примерно на 14% медленнее, высота голоса сохранена.

- Книга — авторский учебный макет, не факсимиле издания. Дополнительная нагрузка — поясняющая схема, не заявление о существовании древнего привода.
- Мягкий студийный свет, контактные тени, макропланы и плавные дуги камеры. Физические процессы показаны условно; размеры и скорости не археологические измерения.
- Источники и пределы утверждений: FACTS.md. Собственная процедурная музыка и эффекты; никаких платных API или чужого видеоряда.

## Сборка

`script.py` → `prepare_edge_audio.py` → `make_native.py` → `prepare_v2.py` → `render.mjs` → `finish_v2.py` → `verify.py`. Канонический workflow: `.github/workflows/heron_v2.yml`.

32 части большого ролика и 8 частей двух Shorts; не больше 20 бесплатных публичных раннеров одновременно. Готовые файлы — GitHub Release; до 95 МБ также `videos/`. Модели, Chromium и node_modules в git не попадают.

Автоматические проверки — длительность 10–15 минут, H.264/yuv420p/30 fps/AAC, полное декодирование, отсутствие перегруза. Проверка кадров и полное восприятие движения/звука — разные вещи: выборочные кадры и ASR не называются полным человеческим просмотром.

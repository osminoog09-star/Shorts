# Герон: автоматы без электричества

Отдельный авторский выпуск Codex. Проект Клода `../antikythera` не изменяется.

- 1920×1080, 30 fps, русский язык; длительность определяется полноценной речью, целевой диапазон 8–10 минут.
- Самостоятельные процедурные Three.js-модели. Пастель, скруглённые формы, студийное освещение, матовые/металлические поверхности, мягкая контактная тень и глубинный фокус в крупных планах.
- Это учебная реконструкция описаний, не изображение сохранившихся древних оригиналов.
- `script.py` → `prepare_edge_audio.py` → `render.mjs` (независимые диапазоны кадров) → `compose.py`.
- Никаких платных API; единый голос ru-RU-DmitryNeural из общего workflow TTS, музыка и эффекты процедурные, собственные.
- Финальная приёмка включает декодирование MP4, границы сцен, визуальную проверку, длительность и проверку звука. Наличие файлов не означает художественную приёмку.

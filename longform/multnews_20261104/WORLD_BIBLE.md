# M1lash МультНовости #01 — библия больших миров (S3-D25)

Действует только для отдельного мультфильма 21–23мин «ИИ вышел на работу». Это **редакторская постановка**, не отменяет `AGENTS.md`; все компании и факты — `FACTS.md`, вымышленные Болтик и сцены не выдаются за документальную видеозапись. **Никаких синтетических заводских SFX**, только будущая реальная авторская озвучка Дениса по Qwen3-TTS и одобренная концовка. Нет публикации без «ок» владельца.

## Единая стилистика

- S3-D25: чистый выразительный контур/комикс, материал и фактура, большие окружающие пространства, три и более независимых глубинных плана, предметное действие, осмысленная камера. Для техногенной сцены 3+ функциональных зон, а не одна плоскость с повторными коробками/механизмами.
- Сквозной персонаж Болтик с одной лицевой маской, знаком на груди, ступнями на полу, понятными кистями, реальными предметами; держать размер героя маленьким на общих планах. Силуэт и палитру проверять по модельному листу, а не перерисовывать каждый эпизод новым роботом.
- Отделять экранный HUD от world camera. Логотипы, маркировка `ФАКТ/СКЕТЧ` и источники — на отдельном 1920×1080 HUD. Предметы проверять в world и screen координатах.
- В каждом событии: цель → попытка → контакт/изменение среды → реакция → следствие. Не статичные разлёты квадратиков и не независимый `Math.sin` вместо физической причины.

## Pipeline для каждого мира

1. На основе главы `SCRIPT.md` выписать 5–8 предметных **новых действий**, не 5–8 положений камеры над старой картинкой.
2. Описать карту глубин, свет, реквизит, участников; нарисовать кодом HTML/SVG/HyperFrames/Three.js. Сначала 4–6 **разных** реальных стопов 1920×1080.
3. Физический контакт — anchor от фактической точки предмета/инструмента, общие event timers и отдельные скрин-кадры t−.2/t/t+.2; каждый переход кадра проверять в screen space.
4. Отдельный 8–20-секундный видеопилот без аудиопотока; FFmpeg full decode, ffprobe streams=video only, 1fps + событие по 0.5sec, mobile 360px. `TECH_PASS` не означает `ART_GO`.
5. После появления реальных private voice WAV Qwen Дениса — пересчитать тайминг всех сцен и 190+ смысловых планов, смонтировать по главам, approved outro, official финальный QA/публикация только с отдельным «ок».

# Бесплатный видео-конвейер M1lash (27.10.2026)

Документ выбора инструментов для Codex/Claude. Предпочитать локальные/бесплатные способы. Наличие скилла **не означает бесплатный API**. Проверять лицензию каждой модели/ассета перед монетизацией.

## Подключено

- Remotion Agent Skills: **уже установлены** в `.agents/skills/remotion-*` и `.claude/skills/remotion-*`; не переустанавливать и не затирать существующие кастомизации.
- ElevenLabs Agent Skills: установлен официальный пакет инструкций в обе агентские директории, но ElevenLabs API **не** активирован: для TTS/SFX/музыки нужен ключ `ELEVENLABS_API_KEY` и бесплатный баланс или оплата. Не ставить платные запросы по умолчанию.

## Ограничения для монетизации

- **Не использовать** Silero TTS без отдельной коммерческой лицензии: модели `CC-BY-NC` / некоммерческие (см. официальный README: https://github.com/snakers4/silero-models).
- **Не использовать** Wav2Lip в коммерческих/монетизируемых роликах без нужного разрешения: исходный проект помечен non-commercial (https://github.com/Rudrabha/Wav2Lip).
- Для Piper проверить `MODEL_CARD` конкретного голоса; даже если модель называется `dmitri`, она **не идентична** `ru-RU-DmitryNeural`.

## Правила производства (наследуются от AGENTS.md)

1. **Только один согласованный голос на протяжении видео.** Для текущих M1lash RU-новостей — `ru-RU-DmitryNeural`. Не делать скрытого fallback на иной тембр. Если голос недоступен, корректно останавливать сборку.
2. Использовать уже утверждённого ведущего и фирменную концовку из репозитория; не менять персонажа случайным аватаром.
3. Не подменять киновырезками авторский оригинальный материал без достаточного разрешения; источники и лицензии хранить в манифесте.
4. Экспорт готового MP4, проверить звук, видеокодек, длительность, начало/конец, визуальные сцены. Отмечать непроверенное.
5. Не публиковать автоматически; действующие слоты YouTube/Metricool и чужие ветки не трогать.
6. Не создавать API-запросы в платные сервисы без согласованного бюджета.

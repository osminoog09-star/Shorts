# M1lash V4 — пилот качества героев, 2026-10-27

## Проверенный артефакт

Локально создан `M1lash_PILOT_V4_CHARACTER_LOOK_DIRECTOR_CUT.mp4` (43,85 с, 960×540, 20 fps, H.264/AAC, 4 061 140 байт). Сохранена полная оригинальная аудиодорожка Дмитрия из V3. Полное декодирование через FFmpeg прошло без ошибок.

## Что изменилось по сравнению с V3

- Перестал рисовать директора и робота упрощёнными кругами и линиями; используется утверждённая высококачественная иллюстрация `директор_нажимает_красную_кнопку.png` и панельная постановка `офисная_битва_босс_против_ии.png`.
- Создано 13 монтажных секций с планами директора, кнопки, сотрудников, робота и конфликта.
- Применены небольшие локальные деформации и движения камеры; сами персонажи *не* имеют полноценной артикуляции, актёрских жестов или lip-sync.
- Сборочный скрипт доступен в локальных исходниках теста `/mnt/data/m1lash_v4_beauty.py`; файл локальный, не опубликован в Github.

## QA

Технически PASS; художественно NO-GO. Скачиваемый MP4 **не** равен полноценному video-to-video преобразованию, а динамическому монтажу хороших статичных кадров. Не утверждать иного.

## Следующие реальные задачи

1. Извлечь из утверждённых изображений многослойные персонажные ассеты с восстановленными скрытыми зонами (вручную/с масками).
2. Прикрепить полученные части к IK-костям из `tools/m1lash_character_rig/ik.py` с проверкой, что конечности не отрываются.
3. Сделать 4–8 секунд **реального** движения: контакт руки с кнопкой, изменение позы тела, реакции коллег, моргание и артикуляция. Отдельная QA без звука.
4. Синхронизировать выбранную полную фразу Дмитрия с настоящим действием и затем собрать пилот с 1080p.
5. Только после режиссёрского GO возвращаться к полному фильму.

**Урок для навыка:** качественные красивые модельные изображения решают проблему стиля, но не решают проблему движения. Подменять анимацию движением камеры запрещено, как и подменять улучшение движения заменой статичных планов.

### Архив предыдущих правил киноразборов (неисполняемый)

**Решение Дениса 30.10 по анализу канала** (`reports/youtube/snapshot-2026-10-30.json`): длинные набирали 0–29 просмотров — YouTube их не показывал (97 % аудитории — неподписанные зрители ленты Shorts, темы длинных не связаны с тем, за чем пришли). Поэтому:
- **Новый тестовый формат длинного — кино-разбор** («почему эта сцена гениальна», история персонажа) с фрагментами фильма: тема из того, что уже работает в Shorts (кино-Shorts — 2,2 тыс. в среднем, лидер). Риск Content ID принят (раздел 8).
- **Историческое решение Дениса 04.11 для ПЕРВОЙ версии киноразбора «Антон Чигур» (`RJEZKHegzUY`): ТОЛЬКО материал реального фильма, БЕЗ нарисованных/кодовых 3D-реконструкций.** Авторский голос Дениса раскрывает анализ на разнообразных оригинальных планах фильма (герои, действия, детали, реакции); конкретную интонацию/реплику подтверждает короткая вставка с подлинным русским дубляжом и исходными звуками; когда говорят актёры, автора не накладывать. Для авторской речи использовать видеоряд фильма и аккуратные субтитры/текстовые акценты, а не отдельные заставки/подменные игровые сцены. Не растягивать одинаковые фрагменты и не придумывать «доказательные» моменты, которых нет в исходнике. Работу над V21/V22 CGI для Чигура прекратить, старые 3D assets держать как архив, НЕ включать в финальный монтаж. Это узкое решение по Чигуру и пока не меняет стили остальных видео.
- **НОВОЕ решение Дениса 04.11 после фактической YouTube Content ID заявки — отдельная авторская ВЕРСИЯ A Чигура для проверки монетизации.** ВЛАДЕЛЕЦ ПОДТВЕРДИЛ A: **0% кадров оригинального фильма и 0% оригинального звука актёров** в новой версии, включая фоновые планы, кадры/фото/постер и исходные музыкальные фрагменты. Полностью оригинальный кодовый предметный видеоряд с авторской режиссурой, голосом Дениса (существующие Qwen3 WAV с исправлениями смысла) и точно утверждённой Denis-v7 горизонтальной концовкой. Видеоряд не воссоздаёт персонажей/внешность актёров/узнаваемые кадры фильма: **объясняет кино через авторские предметные метафоры и оригинальные динамичные модели**, включая кассу, жетон, чаши весов, портфель, коридор и кресла. Рендер — HyperFrames/HTML+Three.js+Playwright, НЕ PIL. Контроль: 4–6 оригинальных стопов визуально, 10с пилот, затем full QA, частный YouTube тест только после owner review, никаких гарантированных Content ID-free/YPP исходов. **Старая фильмовая версия `RJEZKHegzUY` остаётся PRIVATE без даты/спора/удаления; не переливать её снова.** Детали `longform/chigur/CONTENT_ID_REEDIT_PLAN_2026-11-04.md` и `reports/research/2026-11-04_CHIGUR_MONETIZABLE_VIDEOESSAY_RESEARCH.md`.

# M1lash S1 body profile V5 — 28 October 2026

## Created and tested
Real MP4 `M1lash_S1_MODEL_V5_TRUE_BODY_PROFILES.mp4`: 6.000 seconds, 960×540, 24fps, H.264, 107084 bytes. Full FFmpeg decode PASS. Generated by fresh `body_v5.py` building on geometry helpers from `body_v4.py`. No external source images, no camera-pan substitute. Intentionally silent technical test.

## Main change
Independent key geometry authored for FRONT, THREE-QUARTER and SIDE for: torso silhouette, shirt, both jacket lapels, near and far arms, hands, legs and shoes. Each set of paths interpolates with a shared angle/time state. In previous V4 the side profile was mostly a narrowed torso; V5 is not merely width scaling.

## Visual review of real decoded frames
- Front: overall recognizably a business character; remains too simplified.
- Three-quarter: layering is stronger than V4 but the line/jaw placement is not cohesive enough.
- Side (t=4.3s): independent nose profile and nearer jacket arm visible. HOWEVER silhouette still resembles geometric doll: body rigidly vertical, huge flat nose, very skinny legs, mitten hands, no center-of-gravity response.
- Transition: drawn view outlines interpolate but head changes among unequal path-point sets by piecewise angle thresholds, causing risk of snapping. Cannot call this smooth professional rotation.
- No real gesture, physical acting, speech or lip-sync in this test.

## Editorial gate (self-reviewed, not audience statistics)
Distinct body-view construction: 6/10; character appeal: 4/10; anatomy/hands: 3/10; shape continuity: 4/10; animation acting: 3/10; environment: 3/10; MP4 technical: 9/10; original voice: not tested. 8/10 in every category is NOT reached, ARTISTIC NO-GO.

## Lessons
1. Separately drawn torso/arm/leg profile geometry is technically preferable to width scaling, but still requires silhouette design, anatomy, costuming and aesthetic review.
2. Path interpolation needs topological correspondence. Switching point-count head paths mid-turn can cause an unnatural pop.
3. Check real side-frame still BEFORE announcing improvement, and assess hands, shoulder structure, foot placement and near/far occlusion.
4. Continue model gate rather than manufacturing a 14-minute episode from weak art.
5. The code must be saved verbatim in repository to make the iteration reproducible; do not report source as committed until it is.

# M1lash V7 — кнопка и кисть (27.10.2026)

Задача: продолжить V6 без панорамирования статичной картинки, проверить реальный контакт указательного пальца с кнопкой.

## Новый тест
- `M1lash_V7_HAND_CONTACT_CORRECTED.mp4` — локальный файл, 6.000 с, 960x540 24 FPS, H.264, 70 933 байта.
- Источник `m1lash_v7_hand_study.py` — модификация V6 в текущем контейнере. Временной процедурный SVG/CairoSVG renderer, анимация позиции кисти и движения кнопки. Не генерировался нейросетью и не является постобработкой готовой фотографии.
- Проверка `ffmpeg -xerror -i ... -f null -`: PASS.

## Действительные исправления
- Центр контакта по X привязан к середине красной кнопки: x = 687 пикселей на фазе максимального нажатия; в V6 кончик был примерно левее на 80 px.
- Вертикальное движение контакта: y кончика = 311+13*contact; y поверхности кнопки = 333+13*contact-22 = 311+13*contact. То есть поверхностные координаты **математически совпадают** при максимальном нажатии.
- Добавлено явное отступление руки и восстановление положения кнопки.

## Независимый визуальный аудит
- Технический decode: PASS.
- Контакт-геометрия 2D: PASS на ключевой фазе по координатам.
- **Качество анатомии и натуральность контакта: NO-GO**. На t=3.0 пальцы выглядят как искусственные линии, индекс — крючок; прямой рукав не формирует нормальное плечо или локоть, и палец лишь пересекает верх кнопки.
- Камера без движения — независимый кодовый render, но художественно это всё ещё простая учебная векторная графика.
- Нет диктора, лиц, полноценной актёрской сцены, звуков; 8/10 по всем категориям НЕ ДОСТИГНУТЫ.

## Урок в навыки
- Математический HITBOX-PASS не равен ART-PASS. Для контакта требовать совпадение точки поверхности, отдельную фазу сжатия подушечки пальца и естественную деформацию ладони/суставов, плюс минимум кадры before/at/after.
- Вынести проверку `world-space target` и рендер контакта в один скрипт, устраняя ручную коррекцию наугад.
- Для следующей версии перестать рисовать целиком вытянутый рукав-полосу: построить rig плечо/локоть/запястье и моделировать пять пальцев с фалангами.
